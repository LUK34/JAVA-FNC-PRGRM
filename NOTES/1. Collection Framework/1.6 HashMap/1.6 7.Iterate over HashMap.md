# Java HashMap – Different Ways to Iterate Over a HashMap

## 1. Objective

In this lecture, we will learn different ways to iterate over a `HashMap`.

The approaches covered are:

1. Using Java 8 `forEach()` with a lambda expression
2. Using `Iterator` on `entrySet()`
3. Using `forEach()` on `entrySet()`
4. Using a simple enhanced `for` loop on `entrySet()`
5. Iterating over `keySet()`

---

# 2. Create a Sample HashMap

```java
import java.util.HashMap;
import java.util.Iterator;
import java.util.Map;

public class IterateOverHashMapExample {

    public static void main(String[] args) {

        Map<String, Integer> fruitMap = new HashMap<>();

        fruitMap.put("Apple", 10);
        fruitMap.put("Banana", 20);
        fruitMap.put("Orange", 15);
        fruitMap.put("Mango", 25);
        fruitMap.put("Cherry", 40);

        System.out.println(fruitMap);
    }
}
```

Conceptually:

```text
Apple   -> 10
Banana  -> 20
Orange  -> 15
Mango   -> 25
Cherry  -> 40
```

Remember that `HashMap` does not guarantee insertion order.

---

# 3. Method 1 – forEach() with Lambda Expression

Java 8 introduced the `forEach()` method.

This is one of the simplest and most concise ways to iterate over a `HashMap`.

Syntax:

```java
map.forEach((key, value) -> {
    // logic
});
```

Example:

```java
fruitMap.forEach((key, value) ->
        System.out.println(key + " -> " + value)
);
```

Possible output:

```text
Apple -> 10
Cherry -> 40
Mango -> 25
Orange -> 15
Banana -> 20
```

The exact order may vary.

---

# 4. How HashMap forEach() Works

The lambda expression receives two parameters:

```text
key
value
```

Example:

```java
fruitMap.forEach((key, value) ->
        System.out.println(key + " -> " + value)
);
```

Conceptually:

```text
HashMap
   |
   v
forEach()
   |
   +---- key
   |
   +---- value
   |
   v
Lambda Expression
```

---

# 5. BiConsumer Functional Interface

The `Map.forEach()` method works with a:

```java
BiConsumer
```

functional interface.

Conceptually:

```text
forEach()
    |
    v
BiConsumer<K, V>
    |
    v
accepts two parameters
    |
    +---- Key
    +---- Value
```

The lambda:

```java
(key, value) ->
        System.out.println(key + " -> " + value)
```

provides the implementation for the `BiConsumer`.

---

# 6. Why This Approach is Popular

This approach is:

* Short
* Concise
* Easy to read
* Available from Java 8 onwards
* Useful when both key and value are required

Example:

```java
fruitMap.forEach((key, value) ->
        System.out.println(key + " -> " + value)
);
```

This is often preferred when only simple iteration is needed.

# 7. Method 2 – Iterator with entrySet()

Another way is to use an `Iterator`.

First obtain the entry set:

```java
fruitMap.entrySet()
```

Then obtain an iterator:

```java
Iterator<Map.Entry<String, Integer>> iterator =
        fruitMap.entrySet().iterator();
```

---

# 8. Iterating Using Iterator

Example:

```java
Iterator<Map.Entry<String, Integer>> iterator =
        fruitMap.entrySet().iterator();

while (iterator.hasNext()) {

    Map.Entry<String, Integer> entry =
            iterator.next();

    System.out.println(
            entry.getKey() + " -> " + entry.getValue()
    );
}
```

---

# 9. How Iterator Works

The important methods are:

```java
hasNext()
next()
```

`hasNext()` checks whether another element is available.

```java
iterator.hasNext();
```

`next()` returns the next entry.

```java
iterator.next();
```

Conceptually:

```text
Iterator
   |
   v
hasNext()
   |
   +---- false -> stop
   |
   +---- true
           |
           v
         next()
           |
           v
      Map.Entry
```

---

# 10. Map.Entry with Iterator

The iterator returns:

```java
Map.Entry<String, Integer>
```

Each `Map.Entry` represents one key-value pair.

Example:

```java
Map.Entry<String, Integer> entry =
        iterator.next();
```

Then:

```java
entry.getKey();
```

returns the key.

And:

```java
entry.getValue();
```

returns the value.

---

# 11. Complete Iterator Example

```java
Iterator<Map.Entry<String, Integer>> iterator =
        fruitMap.entrySet().iterator();

while (iterator.hasNext()) {

    Map.Entry<String, Integer> entry =
            iterator.next();

    String key = entry.getKey();
    Integer value = entry.getValue();

    System.out.println(key + " -> " + value);
}
```

---

# 12. Method 3 – entrySet().forEach() with Lambda

Instead of calling `forEach()` directly on the map, we can first obtain its entry set.

```java
fruitMap.entrySet()
```

Then use:

```java
forEach()
```

Example:

```java
fruitMap.entrySet().forEach(entry ->
        System.out.println(
                entry.getKey() + " -> " + entry.getValue()
        )
);
```

---

# 13. How entrySet().forEach() Works

`entrySet()` returns:

```java
Set<Map.Entry<K, V>>
```

For our map:

```java
Set<Map.Entry<String, Integer>>
```

The lambda therefore receives one parameter:

```java
entry
```

From that entry we obtain:

```java
entry.getKey()
entry.getValue()
```

---

# 14. Map forEach() vs entrySet().forEach()

### Directly on Map

```java
fruitMap.forEach((key, value) ->
        System.out.println(key + " -> " + value)
);
```

The lambda receives:

```text
key
value
```

---

### On entrySet()

```java
fruitMap.entrySet().forEach(entry ->
        System.out.println(
                entry.getKey() + " -> " + entry.getValue()
        )
);
```

The lambda receives:

```text
entry
```

Then the key and value are extracted from that entry.

# 15. Method 4 – Enhanced for Loop with entrySet()

We can also use a traditional enhanced `for` loop.

Example:

```java
for (Map.Entry<String, Integer> entry
        : fruitMap.entrySet()) {

    System.out.println(
            entry.getKey() + " -> " + entry.getValue()
    );
}
```

This is simple and very readable.

---

# 16. How Enhanced for Loop Works

Conceptually:

```text
fruitMap.entrySet()
        |
        v
Set<Map.Entry<String, Integer>>
        |
        v
for each entry
        |
        +---- getKey()
        |
        +---- getValue()
```

Example:

```java
for (Map.Entry<String, Integer> entry
        : fruitMap.entrySet()) {

    String key = entry.getKey();
    Integer value = entry.getValue();
}
```

---

# 17. Method 5 – Iterate Over keySet()

We can retrieve all keys using:

```java
fruitMap.keySet();
```

Then iterate over them.

Example:

```java
fruitMap.keySet().forEach(key ->
        System.out.println(
                key + " -> " + fruitMap.get(key)
        )
);
```

Here:

```java
key
```

represents each key from the map.

The corresponding value is retrieved using:

```java
fruitMap.get(key)
```

---

# 18. keySet() Iteration with Enhanced for Loop

We can also write:

```java
for (String key : fruitMap.keySet()) {

    Integer value = fruitMap.get(key);

    System.out.println(
            key + " -> " + value
    );
}
```

# 21. Complete Example

```java
import java.util.HashMap;
import java.util.Iterator;
import java.util.Map;

public class IterateOverHashMapExample {

    public static void main(String[] args) {

        Map<String, Integer> fruitMap = new HashMap<>();

        fruitMap.put("Apple", 10);
        fruitMap.put("Banana", 20);
        fruitMap.put("Orange", 15);
        fruitMap.put("Mango", 25);
        fruitMap.put("Cherry", 40);

        System.out.println(
                "1. Java 8 forEach() with lambda"
        );

        fruitMap.forEach((key, value) ->
                System.out.println(
                        key + " -> " + value
                )
        );


        System.out.println(
                "\n2. Iterator with entrySet()"
        );

        Iterator<Map.Entry<String, Integer>> iterator =
                fruitMap.entrySet().iterator();

        while (iterator.hasNext()) {

            Map.Entry<String, Integer> entry =
                    iterator.next();

            System.out.println(
                    entry.getKey()
                            + " -> "
                            + entry.getValue()
            );
        }


        System.out.println(
                "\n3. entrySet().forEach() with lambda"
        );

        fruitMap.entrySet().forEach(entry ->
                System.out.println(
                        entry.getKey()
                                + " -> "
                                + entry.getValue()
                )
        );


        System.out.println(
                "\n4. Enhanced for loop with entrySet()"
        );

        for (Map.Entry<String, Integer> entry
                : fruitMap.entrySet()) {

            System.out.println(
                    entry.getKey()
                            + " -> "
                            + entry.getValue()
            );
        }


        System.out.println(
                "\n5. Iterate over keySet()"
        );

        fruitMap.keySet().forEach(key ->
                System.out.println(
                        key
                                + " -> "
                                + fruitMap.get(key)
                )
        );
    }
}
```

# 22. Comparison Table

| Approach               | Main API                   | Gets Key + Value Directly? | Style       |
| ---------------------- | -------------------------- | -------------------------: | ----------- |
| `Map.forEach()`        | `forEach()`                |                      ✅ Yes | Functional  |
| Iterator               | `entrySet().iterator()`    |                      ✅ Yes | Traditional |
| `entrySet().forEach()` | `entrySet()` + `forEach()` |                      ✅ Yes | Functional  |
| Enhanced `for` loop    | `entrySet()`               |                      ✅ Yes | Traditional |
| `keySet()` iteration   | `keySet()` + `get()`       |   ❌ Value requires `get()` | Mixed       |

# 23. Recommended Approach for Simple Iteration

When you only need to process every key-value pair, this is usually the most concise:

```java
fruitMap.forEach((key, value) ->
        System.out.println(key + " -> " + value)
);
```

It directly provides both:

```text
key
value
```

without requiring `Map.Entry`.

---

# 24. When entrySet() is Useful

Use `entrySet()` when you want to work explicitly with map entries.

Example:

```java
for (Map.Entry<String, Integer> entry
        : fruitMap.entrySet()) {
}
```

This gives access to:

```java
entry.getKey();
entry.getValue();
```

---

# 25. When Iterator is Useful

The iterator approach is more verbose:

```java
Iterator<Map.Entry<String, Integer>> iterator =
        fruitMap.entrySet().iterator();
```

But it can be useful when you need explicit iterator operations.

For example:

```java
while (iterator.hasNext()) {
    Map.Entry<String, Integer> entry =
            iterator.next();
}
```

---

# 26. Important Note About Removing Entries While Iterating

One practical reason to use an iterator is when entries need to be safely removed during iteration.

Example:

```java
Iterator<Map.Entry<String, Integer>> iterator =
        fruitMap.entrySet().iterator();

while (iterator.hasNext()) {

    Map.Entry<String, Integer> entry =
            iterator.next();

    if (entry.getValue() < 20) {
        iterator.remove();
    }
}
```

This is safer than directly modifying the map while traversing it with many traditional iteration approaches.

---

# 27. keySet() vs entrySet()

Suppose both key and value are required.

You could write:

```java
for (String key : fruitMap.keySet()) {

    Integer value = fruitMap.get(key);
}
```

But with `entrySet()`:

```java
for (Map.Entry<String, Integer> entry
        : fruitMap.entrySet()) {

    String key = entry.getKey();
    Integer value = entry.getValue();
}
```

The second approach directly provides the entry.

So when both key and value are needed, `entrySet()` is often clearer than iterating keys and calling `get()` repeatedly.


---

## Traditional Style

```java

        : fruitMap.entrySet()) {
}
```

and:

```java

        fruitMap.entrySet().iterator();
```

Both styles are valid.

The best choice depends on what the program needs to do.

# Key Takeaway

The five important ways demonstrated are:

```java
map.forEach((key, value) -> ...);

map.entrySet().iterator();

map.entrySet().forEach(entry -> ...);

for (Map.Entry<K, V> entry : map.entrySet()) {
    ...
}

map.keySet().forEach(key -> ...);
```

For simple Java 8 code, the most concise approach is often:

```java
fruitMap.forEach((key, value) ->
        System.out.println(key + " -> " + value)
);
```

A simple way to remember:

> **Need simple key-value iteration? Use `Map.forEach()`. Need explicit entries? Use `entrySet()`. Need iterator control? Use `Iterator`. Need only keys? Use `keySet()`.**
