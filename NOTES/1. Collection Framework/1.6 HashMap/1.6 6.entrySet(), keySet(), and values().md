# Java HashMap – entrySet(), keySet(), and values()

## 1. Objective

In this lecture, we will learn how to retrieve different views of data stored inside a `HashMap`.

The main methods covered are:

```java
entrySet()
keySet()
values()
```

These methods allow us to retrieve:

* All key-value pairs
* All keys
* All values

---

# 2. Create a Sample HashMap

First, create a `HashMap` containing fruit names and their quantities.

```java
import java.util.Collection;
import java.util.HashMap;
import java.util.Map;
import java.util.Set;

public class HashMapEntryKeySetValuesExample {

    public static void main(String[] args) {

        Map<String, Integer> fruitMap = new HashMap<>();

        fruitMap.put("Apple", 10);
        fruitMap.put("Banana", 20);
        fruitMap.put("Orange", 15);
        fruitMap.put("Mango", 25);
    }
}
```

Conceptually:

```text
Key        Value
----------------
Apple   -> 10
Banana  -> 20
Orange  -> 15
Mango   -> 25
```

# 3. entrySet()

The `entrySet()` method returns a set containing all key-value mappings in the map.

Syntax:

```java
map.entrySet();
```

General method signature:

```java
Set<Map.Entry<K, V>> entrySet()
```

Each element inside this set represents one:

```text
Key -> Value
```

mapping.

---

# 4. Map.Entry Interface

The `Map` interface contains a nested interface called:

```java
Map.Entry
```

A `Map.Entry` object represents one key-value pair.

For example:

```text
Apple -> 10
```

can be represented as one:

```java
Map.Entry<String, Integer>
```

Conceptually:

```text
Map
 |
 +-- Entry
      |
      +-- Key
      |
      +-- Value
```

---

# 5. Retrieving All Entries

Example:

```java
Set<Map.Entry<String, Integer>> entries =
        fruitMap.entrySet();
```

Here:

```text
Set
 |
 +-- Map.Entry<String, Integer>
       |
       +-- String  -> Key type
       |
       +-- Integer -> Value type
```

The `entries` variable contains all key-value mappings.

Example:

```java
System.out.println(
        "Entry set - Key value pairs: " + entries
);
```

Possible output:

```text

[Apple=10, Mango=25, Orange=15, Banana=20]
```

Each entry is displayed as:

```text

```


# 7. Iterating Over entrySet()

`entrySet()` is commonly used when we need both the key and the value.

Example:

```java

    System.out.println(
            entry.getKey() + " -> " + entry.getValue()
    );
}
```

Possible output:

```text
Apple -> 10
Banana -> 20
Orange -> 15
Mango -> 25
```

The order may vary.

# 13. Retrieving Values Using Keys

If you iterate through `keySet()`, you can retrieve each corresponding value using `get()`.

Example:

```java
for (String key : fruitMap.keySet()) {

    Integer value = fruitMap.get(key);

    System.out.println(
            key + " -> " + value
    );
}
```

This works, although when you need both key and value, `entrySet()` is usually more direct.

# 18. Why values() Returns Collection Instead of Set

This is an important point.

`keySet()` returns:

```java
Set<K>
```

because keys in a `HashMap` must be unique.

But `values()` returns:

```java
Collection<V>
```

because values are allowed to be duplicated.

For example:

```java
Map<String, Integer> map = new HashMap<>();

map.put("Apple", 10);
map.put("Banana", 10);
map.put("Orange", 10);
```

This is valid.

Therefore:

```java
map.values();
```

may contain:

```text
[10, 10, 10]
```

Since duplicate values are allowed, returning a `Set` would be incorrect.

---

# 19. Why keySet() Returns Set

Keys must be unique in a `HashMap`.

For example:

```java
fruitMap.put("Apple", 10);
fruitMap.put("Apple", 20);
```

There will still be only one `"Apple"` key.

Therefore:

```java
fruitMap.keySet();
```

naturally returns a:

```java
Set<String>
```

because a `Set` does not contain duplicate elements.

---

# 20. Why entrySet() Returns Set

Each key in a map is unique.

Therefore, each key-value mapping is also unique with respect to its key.

That is why:

```java
entrySet()
```

returns:

```java
Set<Map.Entry<K, V>>
```

---

# 21. entrySet() vs keySet() vs values()

| Method       | Returns               | Contains        |
| ------------ | --------------------- | --------------- |
| `entrySet()` | `Set<Map.Entry<K,V>>` | Key-value pairs |
| `keySet()`   | `Set<K>`              | Keys only       |
| `values()`   | `Collection<V>`       | Values only     |

# 23. Complete Example

```java
import java.util.Collection;
import java.util.HashMap;
import java.util.Map;
import java.util.Set;

public class HashMapEntryKeySetValuesExample {

    public static void main(String[] args) {

        Map<String, Integer> fruitMap = new HashMap<>();

        fruitMap.put("Apple", 10);
        fruitMap.put("Banana", 20);
        fruitMap.put("Orange", 15);
        fruitMap.put("Mango", 25);

        // Get all key-value pairs
        Set<Map.Entry<String, Integer>> entries =
                fruitMap.entrySet();

        System.out.println(
                "Entry set - Key value pairs: " + entries
        );

        // Get all keys
        Set<String> keys = fruitMap.keySet();

        System.out.println(
                "Key set - All keys: " + keys
        );

        // Get all values
        Collection<Integer> values =
                fruitMap.values();

        System.out.println(
                "Values - All values: " + values
        );
    }
}
```

Possible output:

```text
Entry set - Key value pairs:
[Apple=10, Mango=25, Orange=15, Banana=20]

Key set - All keys:
[Apple, Mango, Orange, Banana]

Values - All values:
[10, 25, 15, 20]
```

The exact order may vary.

# 24. Complete Iteration Example

A very common real-world use case is iterating through the map.

```java
import java.util.HashMap;
import java.util.Map;

public class HashMapIterationExample {

    public static void main(String[] args) {

        Map<String, Integer> fruitMap = new HashMap<>();

        fruitMap.put("Apple", 10);
        fruitMap.put("Banana", 20);
        fruitMap.put("Orange", 15);
        fruitMap.put("Mango", 25);

        for (Map.Entry<String, Integer> entry
                : fruitMap.entrySet()) {

            System.out.println(
                    entry.getKey()
                            + " -> "
                            + entry.getValue()
            );
        }
    }
}
```

Possible output:

```text
Apple -> 10
Banana -> 20
Orange -> 15
Mango -> 25
```

# 25. Which Method Should You Use?

Use:

```java
entrySet()
```

when you need:

```text
Key + Value
```

Example:

```java
for (Map.Entry<String, Integer> entry
        : fruitMap.entrySet()) {
}
```

---

Use:

```java
keySet()
```

when you only need:

```text
Keys
```

Example:

```java
for (String key : fruitMap.keySet()) {
}
```

---

Use:

```java
values()
```

when you only need:

```text
Values
```

Example:

```java
for (Integer value : fruitMap.values()) {
}
```

# 27. Important Point – These Are Views of the Map

An important concept is that:

```java
entrySet()
keySet()
values()
```

return **views backed by the original map**.

They are not completely independent copies.

Example:

```java
Set<String> keys = fruitMap.keySet();
```

If the map later changes:

```java
fruitMap.put("Pineapple", 30);
```

the `keys` view also reflects the change.

Conceptually:

```text
fruitMap
    |
    +---- keySet()
    |
    +---- entrySet()
    |
    +---- values()
```

All of these are connected to the original map.

---

# 28. Modification Through keySet()

Because `keySet()` is backed by the map, removing a key through the returned set can remove the corresponding mapping.

Example:

```java
Set<String> keys = fruitMap.keySet();

keys.remove("Apple");
```

This also removes:

```text
Apple -> 10
```

from `fruitMap`.

This is an important advanced point.

# Key Takeaway

The three important methods from this lecture are:

```java
entrySet()
keySet()
values()
```

Remember them as:

```text
entrySet() -> All key-value pairs

keySet()   -> All keys

values()   -> All values
```

And remember the return types:

```text
entrySet() -> Set<Map.Entry<K,V>>

keySet()   -> Set<K>

values()   -> Collection<V>
```

The easiest memory rule is:

> **Need both key and value? Use `entrySet()`. Need only keys? Use `keySet()`. Need only values? Use `values()`.**
