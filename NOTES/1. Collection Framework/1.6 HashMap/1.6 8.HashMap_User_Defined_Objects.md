# Java HashMap with User-Defined Objects

## 1. Objective

In this lecture, we learn how to create and work with a `HashMap` that stores **user-defined objects**.

The main idea is:

```java
Map<Integer, Employee>
```

where:

- `Integer` is the key type
- `Employee` is the value type
- Employee ID is used as the key
- The complete `Employee` object is stored as the value

---

# 2. What is a User-Defined Object?

A user-defined object is an object created from a class that we define ourselves.

In this example, we create an:

```java
Employee
```

class.

The `Employee` class contains:

```text
Employee
   |
   +-- id
   +-- firstName
   +-- lastName
   +-- email
```

Each `Employee` object represents one employee.

---

# 3. Create the Employee Class

First, create an `Employee` class.

```java
class Employee {

    private int id;
    private String firstName;
    private String lastName;
    private String email;
}
```

The fields represent:

| Field | Type | Description |
|---|---|---|
| `id` | `int` | Employee ID |
| `firstName` | `String` | Employee first name |
| `lastName` | `String` | Employee last name |
| `email` | `String` | Employee email |

---

# 4. Create a Parameterized Constructor

A parameterized constructor allows us to create an `Employee` object and initialize all fields at the same time.

```java
public Employee(
        int id,
        String firstName,
        String lastName,
        String email) {

    this.id = id;
    this.firstName = firstName;
    this.lastName = lastName;
    this.email = email;
}
```

Example:

```java
Employee employee =
        new Employee(
                101,
                "Ramesh",
                "Fadatare",
                "ramesh@gmail.com"
        );
```

---

# 5. Create Getter Methods

Getter methods allow us to read the values stored inside an `Employee` object.

```java
public int getId() {
    return id;
}

public String getFirstName() {
    return firstName;
}

public String getLastName() {
    return lastName;
}

public String getEmail() {
    return email;
}
```

Setter methods are not required in this example because the fields are initialized using the constructor.

---

# 6. Override toString()

The `toString()` method allows the `Employee` object to be printed in a readable format.

```java
@Override
public String toString() {
    return "Employee{" +
            "id=" + id +
            ", firstName='" + firstName + '\'' +
            ", lastName='" + lastName + '\'' +
            ", email='" + email + '\'' +
            '}';
}
```

Without a useful `toString()` implementation, printing an object would not show its field values in the desired readable form.

# 8. Create a HashMap of Employee Objects

Now create a `HashMap`.

```java
Map<Integer, Employee> employeeMap =
        new HashMap<>();
```

Here:

```text
Integer  -> Key type
Employee -> Value type
```

Conceptually:

```text
Employee ID     Employee Object
-----------     ----------------
101          -> Employee(...)
102          -> Employee(...)
103          -> Employee(...)
```

---

# 9. Why Use Employee ID as the Key?

Each employee can be identified using a unique employee ID.

For example:

```text
101 -> Ramesh
102 -> Pramod
103 -> Sanjay
```

Therefore, the map can be declared as:

```java
Map<Integer, Employee>
```

The employee ID acts as the key while the complete employee object acts as the value.

---

# 10. Add Employee Objects to the HashMap

Use the `put()` method.

```java
                "Fadatare",
                "ramesh@gmail.com"
```

Here:

```text
Key   = 101
```

# 12. Complete Program

```java
import java.util.HashMap;
import java.util.Map;

public class HashMapUserDefinedObjectsExample {

    public static void main(String[] args) {

        Map<Integer, Employee> employeeMap =
                new HashMap<>();

        employeeMap.put(
                101,
                new Employee(
                        101,
                        "Ramesh",
                        "Fadatare",
                        "ramesh@gmail.com"
                )
        );

        employeeMap.put(
                102,
                new Employee(
                        102,
                        "Pramod",
                        "Jadhav",
                        "pramod@gmail.com"
                )
        );

        employeeMap.put(
                103,
                new Employee(
                        103,
                        "Sanjay",
                        "Pawar",
                        "sanjay@gmail.com"
                )
        );

        System.out.println(employeeMap);
    }
}


class Employee {

    private int id;
    private String firstName;
    private String lastName;
    private String email;

    public Employee(
            int id,
            String firstName,
            String lastName,
            String email) {

        this.id = id;
        this.firstName = firstName;
        this.lastName = lastName;
        this.email = email;
    }

    public int getId() {
        return id;
    }

    public String getFirstName() {
        return firstName;
    }

    public String getLastName() {
        return lastName;
    }

    public String getEmail() {
        return email;
    }

    @Override
    public String toString() {
        return "Employee{" +
                "id=" + id +
                ", firstName='" + firstName + '\'' +
                ", lastName='" + lastName + '\'' +
                ", email='" + email + '\'' +
                '}';
    }
}
```

# 15. Retrieve an Employee Using the Key

Once an employee object is stored, it can be retrieved using `get()`.

Example:

```java
Employee employee =
        employeeMap.get(101);
```

This retrieves the employee associated with key:

```text
101
```

We can then access the fields using getters.

```java
System.out.println(employee.getFirstName());
System.out.println(employee.getLastName());
System.out.println(employee.getEmail());
```

---

# 18. Iterate Over Employee Objects

We can iterate over the complete map using `forEach()`.

```java
employeeMap.forEach((id, employee) -> {

    System.out.println(
            id + " -> " + employee
    );
});
```

Here:

```text
id       -> Integer key
employee -> Employee object
```

---

# 19. Iterate Using entrySet()

Another option is:

```java
for (Map.Entry<Integer, Employee> entry
        : employeeMap.entrySet()) {

    Integer employeeId =
            entry.getKey();

    Employee employee =
            entry.getValue();

    System.out.println(
            employeeId + " -> " + employee
    );
}
```

---

# 20. Iterate Over Employee Values Only

If we only need the employee objects:

```java
for (Employee employee
        : employeeMap.values()) {

    System.out.println(employee);
}
```

Because:

```java
employeeMap.values()
```

returns the employee objects stored as values.

# 21. Generic Type Explanation

Consider:

```java
Map<Integer, Employee> employeeMap =
        new HashMap<>();
```

The generic types are:

```text
Map<K, V>
```

where:

```text
K = Integer
V = Employee
```

Therefore:

```text
Map<Integer, Employee>
        |
        +---- Integer  -> Key
        |
        +---- Employee -> Value
```

---

# 22. HashMap Can Store Any Object Type

`HashMap` values do not have to be simple types such as:

```java
String
Integer
Double
```

They can also be objects created from our own classes.

For example:

```java
Map<Integer, Employee>
```

or:

```java
Map<Integer, Student>
```

or:

```java
Map<String, Product>
```

or:

```java
Map<Long, Customer>
```

The type of object depends on the application's requirements.

# 25. Important Interview Questions

## Can HashMap store user-defined objects?

Yes.

For example:

```java
Map<Integer, Employee> employeeMap =
        new HashMap<>();
```

Here, `Employee` is a user-defined class.

---

## Can a user-defined object be the value of a HashMap?

Yes.

Example:

```java
Map<Integer, Employee>
```

where:

```text
Integer  -> Key
Employee -> Value
```

---

## Can a user-defined object also be used as a HashMap key?

Yes, Java allows user-defined objects to be used as keys as well.

However, when custom objects are used as keys, `equals()` and `hashCode()` become very important.

That is a separate concept from this lecture, where `Integer` is being used as the key.

---

## Why is toString() useful?

It makes an object display its field values in a readable format when printed.

Example:

```java
System.out.println(employee);
```

internally uses:

```java
employee.toString();
```

---

## Why are getter methods used?

Getter methods allow other code to read private fields.

For example:

```java
employee.getFirstName();
```

# 28. Key Takeaway

A `HashMap` can store user-defined objects just like it stores built-in Java types.

For this example:

```java
Map<Integer, Employee> employeeMap =
        new HashMap<>();
```

means:

```text
Integer  -> Employee ID used as key
Employee -> Complete employee object used as value
```

Objects are inserted using:

```java
employeeMap.put(employeeId, employeeObject);
```

and retrieved using:

```java
employeeMap.get(employeeId);
```

The easiest way to remember this example is:

> **Employee ID is the key, and the Employee object containing all employee details is the value.**
