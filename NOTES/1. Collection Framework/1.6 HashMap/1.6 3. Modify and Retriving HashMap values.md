# Java HashMap – Modifying and Retrieving Values

## 1. Objective

In this lecture, we will learn how to:

* Check whether a specific **value** exists in a `HashMap`
* Retrieve the value associated with a specific key
* Understand what `get()` returns when a key does not exist
* Update the value of an existing key using `put()`

The main methods covered are:

```java
containsValue()
get()
put()
```

---

# 2. Create a HashMap

First, create a `HashMap` and add some sample fruit data.

```java
import java.util.HashMap;
import java.util.Map;

public class ModifyAndRetrieveHashMapExample {

    public static void main(String[] args) {

        Map<String, Integer> fruitMap = new HashMap<>();

        fruitMap.put("Apple", 10);
        fruitMap.put("Banana", 20);
        fruitMap.put("Orange", 15);
        fruitMap.put("Grapes", 30);
    }
}
```

Conceptually:

```text
Key        Value
----------------
Apple   -> 10
Banana  -> 20
Orange  -> 15
Grapes  -> 30
```

---

# 3. Checking Whether a Value Exists Using containsValue()

The `containsValue()` method checks whether a specific value is present in the map.

Syntax:

```java
map.containsValue(value);
```

The method returns:

```text
true  -> if the value exists
false -> if the value does not exist
```

The general method signature is:

```java
boolean containsValue(Object value)
```

---

# 4. containsValue() Example

Suppose we want to check whether any fruit has a count of `20`.

```java
if (fruitMap.containsValue(20)) {
    System.out.println("There is a fruit with count of 20");
} else {
    System.out.println("No fruit has a count of 20");
}
```

Since:

```text
Banana -> 20
```

the condition evaluates to:

```text
true
```

Output:

```text
There is a fruit with count of 20
```

---

# 5. containsValue() With a Missing Value

Consider:

```java
if (fruitMap.containsValue(100)) {
    System.out.println("Value exists");
} else {
    System.out.println("Value does not exist");
}
```

There is no value `100` in the map.

Therefore:

```java
fruitMap.containsValue(100);
```

returns:

```text
false
```

Output:

```text
Value does not exist
```

---

# 6. containsKey() vs containsValue()

Do not confuse:

```java
containsKey()
```

with:

```java
containsValue()
```

Example:

```java
fruitMap.containsKey("Banana");
```

checks whether the **key** `"Banana"` exists.

While:

```java
fruitMap.containsValue(20);
```

checks whether the **value** `20` exists.

Comparison:

| Method                 | Checks                            |
| ---------------------- | --------------------------------- |
| `containsKey(key)`     | Whether a particular key exists   |
| `containsValue(value)` | Whether a particular value exists |

---

# 7. Retrieving a Value Using get()

The `get()` method retrieves the value associated with a particular key.

Syntax:

```java
map.get(key);
```

General method signature:

```java
V get(Object key)
```

For:

```java
Map<String, Integer> fruitMap
```

the returned value will be an:

```java
Integer
```

---

# 8. get() Example

Suppose we want to retrieve the count associated with `"Apple"`.

```java
Integer count = fruitMap.get("Apple");

System.out.println("Apple count: " + count);
```

Since the map contains:

```text
Apple -> 10
```

the returned value is:

```text
10
```

Output:

```text
Apple count: 10
```

---

# 9. How get() Works

Conceptually:

```text
fruitMap.get("Apple")
        |
        v
Search for key "Apple"
        |
        v
Apple -> 10
        |
        v
Return 10
```

Therefore:

```java
Integer count = fruitMap.get("Apple");
```

results in:

```text
count = 10
```

---

# 10. What Happens if the Key Does Not Exist?

Suppose we execute:

```java
fruitMap.get("Mango");
```

But `"Mango"` does not exist in the map.

In this situation, `get()` returns:

```text
null
```

Example:

```java
System.out.println("Mango count: " + fruitMap.get("Mango"));
```

Output:

```text
Mango count: null
```

---

# 11. Important Point About get()

Remember:

```text
Existing key
     |
     v
get(key)
     |
     v
Returns associated value
```

But:

```text
Missing key
     |
     v
get(key)
     |
     v
Returns null
```

Example:

```java
fruitMap.get("Apple");
```

returns:

```text
10
```

while:

```java
fruitMap.get("Mango");
```

returns:

```text
null
```

---

# 12. Be Careful With null

There is an important detail when using `get()`.

A returned `null` does not always necessarily mean the key is absent.

Consider:

```java
fruitMap.put("Mango", null);
```

Now:

```java
fruitMap.get("Mango");
```

also returns:

```text
null
```

Therefore, these two situations both return `null`:

```text
Case 1:
"Mango" does not exist

Case 2:
"Mango" exists but is mapped to null
```

If you need to distinguish between them, use:

```java
containsKey()
```

Example:

```java
if (fruitMap.containsKey("Mango")) {
    System.out.println("Mango key exists");
}
```

This is an important practical point.

# 13. Updating an Existing Value Using put()

The `put()` method can be used for two purposes:

```text
1. Add a new key-value pair
2. Update the value of an existing key
```

Suppose the map contains:

```text
Banana -> 20
```

We want to update the value to:

```text
Banana -> 25
```

We can use:

```java
fruitMap.put("Banana", 25);
```

---

# 14. Updating Existing Key Example

Before:

```java
fruitMap.put("Banana", 20);
```

Map:

```text
Banana -> 20
```

Now execute:

```java
fruitMap.put("Banana", 25);
```

Since `"Banana"` already exists, the old value is replaced.

After:

```text
Banana -> 25
```

---

# 15. Confirming the Updated Value

We can retrieve the new value using `get()`.

```java
System.out.println(
        "Updated Banana count: " + fruitMap.get("Banana")
);
```

Output:

```text
Updated Banana count: 25
```

---

# 16. put() Behaviour

The behavior of `put()` depends on whether the key already exists.

### Case 1: New Key

```java
fruitMap.put("Mango", 12);
```

If `"Mango"` does not exist:

```text
Mango -> 12
```

is added.

---

### Case 2: Existing Key

```java
fruitMap.put("Banana", 25);
```

If the map already contains:

```text
Banana -> 20
```

the result becomes:

```text
Banana -> 25
```

The old value is replaced.

---

# 17. put() Return Value

An important point is that `put()` returns the previous value associated with the key.

Example:

```java
Integer oldValue = fruitMap.put("Banana", 25);
```

If `"Banana"` previously contained:

```text
20
```

then:

```text
oldValue = 20
```

The map now contains:

```text
Banana -> 25
```

Example:

```java
Integer oldValue = fruitMap.put("Banana", 25);

System.out.println("Old value: " + oldValue);
System.out.println("New value: " + fruitMap.get("Banana"));
```

Output:

```text
Old value: 20
New value: 25
```

---

# 18. Complete Example

```java
import java.util.HashMap;
import java.util.Map;

public class ModifyAndRetrieveHashMapExample {

    public static void main(String[] args) {

        Map<String, Integer> fruitMap = new HashMap<>();

        fruitMap.put("Apple", 10);
        fruitMap.put("Banana", 20);
        fruitMap.put("Orange", 15);
        fruitMap.put("Grapes", 30);

        // Check whether a particular value exists
        if (fruitMap.containsValue(20)) {
            System.out.println("There is a fruit with count of 20");
        } else {
            System.out.println("No fruit has a count of 20");
        }

        // Retrieve value using key
        Integer appleCount = fruitMap.get("Apple");

        System.out.println("Apple count: " + appleCount);

        // Retrieve a value for a key that does not exist
        System.out.println("Mango count: " + fruitMap.get("Mango"));

        // Update the value of an existing key
        fruitMap.put("Banana", 25);

        System.out.println(
                "Updated Banana count: " + fruitMap.get("Banana")
        );
    }
}
```

Possible output:

```text
There is a fruit with count of 20
Apple count: 10
Mango count: null
Updated Banana count: 25
```

# 20. Quick Comparison

| Method                 | Purpose                       | Return Type     |
| ---------------------- | ----------------------------- | --------------- |
| `containsValue(value)` | Checks whether a value exists | `boolean`       |
| `containsKey(key)`     | Checks whether a key exists   | `boolean`       |
| `get(key)`             | Retrieves the value for a key | Value or `null` |
| `put(key, value)`      | Adds or updates a mapping     | Previous value  |

# 23. Important Interview Points

### How do you check whether a specific value exists in a HashMap?

Use:

```java
containsValue()
```

Example:

```java
map.containsValue(20);
```

---

### How do you retrieve a value from HashMap?

Use:

```java
get(key)
```

Example:

```java
map.get("Apple");
```

---

### What does get() return if the key does not exist?

```text
null
```

---

### How do you update an existing value in HashMap?

Use:

```java
put(key, newValue)
```

Example:

```java
map.put("Banana", 25);
```

---

### What happens when put() is used with an existing key?

The old value is replaced with the new value.

---

### How can you determine whether a null returned by get() means the key is absent?

Use:

```java
containsKey(key)
```

because `get()` may also return `null` when the key exists but is mapped to `null`.

The three important methods from this lecture are:

```java
containsValue()
get()
put()
```

Remember them as:

```text
containsValue()
      |
      +---- Does this VALUE exist?


get()
      |
      +---- Give me the VALUE for this KEY
```
