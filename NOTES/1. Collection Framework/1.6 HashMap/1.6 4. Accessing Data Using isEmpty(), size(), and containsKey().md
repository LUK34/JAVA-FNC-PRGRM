# Java HashMap – Accessing Data Using isEmpty(), size(), and containsKey()

## 1. Objective

In this lecture, we will learn how to:

* Check whether a `HashMap` is empty using `isEmpty()`
* Find the total number of key-value pairs using `size()`
* Check whether a specific key exists using `containsKey()`

The main methods covered are:

```java
isEmpty()
size()
containsKey()
```

---

# 2. Create a HashMap

First, create a `HashMap` for storing fruit names and their quantities.

```java
import java.util.HashMap;
import java.util.Map;

public class AccessHashMapExample {

    public static void main(String[] args) {

        Map<String, Integer> fruitMap = new HashMap<>();

        fruitMap.put("Apple", 10);
        fruitMap.put("Banana", 20);
        fruitMap.put("Orange", 15);
    }
}
```

Conceptually:

```text
Key        Value
----------------
Apple   -> 10
Banana  -> 20
Orange  -> 15
```

---

# 3. Checking Whether a HashMap is Empty

The `isEmpty()` method checks whether the map contains any key-value pairs.

Syntax:

```java
map.isEmpty();
```

The method returns a `boolean` value.

```text
true  -> Map contains no entries
false -> Map contains one or more entries
```

---

# 4. isEmpty() Example Before Adding Data

Consider:

```java
Map<String, Integer> fruitMap = new HashMap<>();

System.out.println("Is the fruit map empty? " + fruitMap.isEmpty());
```

Since no entries have been added yet, the result is:

```text
Is the fruit map empty? true
```

Conceptually:

```text
fruitMap
   |
   v
{}
   |
   v
isEmpty()
   |
   v
true
```

---

# 5. isEmpty() Example After Adding Data

Now add some entries:

```java
fruitMap.put("Apple", 10);
fruitMap.put("Banana", 20);
fruitMap.put("Orange", 15);
```

Then:

```java
System.out.println("Is the fruit map empty? " + fruitMap.isEmpty());
```

Output:

```text
Is the fruit map empty? false
```

Why?

Because the map now contains entries.

```text
Apple   -> 10
Banana  -> 20
Orange  -> 15
```

Therefore:

```text
isEmpty() -> false
```

# 6. isEmpty() Method Summary

The method signature is:

```java
boolean isEmpty()
```

Example:

```java
boolean empty = fruitMap.isEmpty();
```

You can also use it inside an `if` statement.

```java
if (fruitMap.isEmpty()) {
    System.out.println("Fruit map is empty");
} else {
    System.out.println("Fruit map contains data");
}
```

# 7. Getting the Number of Entries Using size()

The `size()` method returns the total number of key-value mappings in the map.

Syntax:

```java
map.size();
```

Suppose the map contains:

```text
Apple   -> 10
Banana  -> 20
Orange  -> 15
```

There are three key-value pairs.

Therefore:

```java
fruitMap.size();
```

returns:

```text
3
```

---

# 8. size() Example

```java
System.out.println(
        "Total fruits in inventory: " + fruitMap.size()
);
```

Output:

```text
Total fruits in inventory: 3
```

The `size()` method returns an `int`.

General method signature:

```java
int size()
```

---

# 9. What Does size() Count?

`size()` counts the number of **entries**, not the sum of the values.

Consider:

```text
Apple   -> 10
Banana  -> 20
Orange  -> 15
```

The map contains:

```text
3 key-value pairs
```

Therefore:

```java
fruitMap.size();
```

returns:

```text
3
```

It does **not** return:

```text
45
```

even though:

```text
10 + 20 + 15 = 45
```

This is an important distinction.

---

# 10. Empty HashMap and size()

Consider:

```java
Map<String, Integer> fruitMap = new HashMap<>();
```

At this point:

```java
fruitMap.size();
```

returns:

```text
0
```

And:

```java
fruitMap.isEmpty();
```

returns:

```text
true
```

Therefore:

```text
size() == 0
```

and:

```text
isEmpty() == true
```

mean that the map currently contains no entries.

# 11. Checking Whether a Key Exists Using containsKey()

The `containsKey()` method checks whether a specific key is present in the map.

Syntax:

```java
map.containsKey(key);
```

It returns a `boolean`.

```text
true  -> Key exists
false -> Key does not exist
```

General method signature:

```java
boolean containsKey(Object key)
```

---

# 12. containsKey() Example

Suppose the map contains:

```text
Apple   -> 10
Banana  -> 20
Orange  -> 15
```

To check whether `"Banana"` exists:

```java
fruitMap.containsKey("Banana");
```

The result is:

```text
true
```

because `"Banana"` is present as a key.

---

# 13. containsKey() with if-else

Example:

```java
if (fruitMap.containsKey("Banana")) {
    System.out.println("Key exists");
} else {
    System.out.println("Key does not exist");
}
```

Output:

```text
Key exists
```

Conceptually:

```text
containsKey("Banana")
        |
        v
Search for Banana
        |
        v
Banana -> 20
        |
        v
      true
```

---

# 14. Checking for a Missing Key

Suppose we check:

```java
fruitMap.containsKey("Mango");
```

But `"Mango"` is not present.

The result is:

```text
false
```

Example:

```java
if (fruitMap.containsKey("Mango")) {
    System.out.println("Key exists");
} else {
    System.out.println("Key does not exist");
}
```

Output:

```text
Key does not exist
```

---

# 15. containsKey() vs containsValue()

Do not confuse:

```java
containsKey()
```

with:

```java
containsValue()
```

Example map:

```text
Banana -> 20
```

This:

```java
fruitMap.containsKey("Banana");
```

checks:

```text
Does the KEY "Banana" exist?
```

Result:

```text
true
```

While:

```java
fruitMap.containsValue(20);
```

checks:

```text
Does the VALUE 20 exist?
```

Result:

```text
true
```

Comparison:

| Method                 | Purpose                       |
| ---------------------- | ----------------------------- |
| `containsKey(key)`     | Checks whether a key exists   |
| `containsValue(value)` | Checks whether a value exists |

---

# 16. containsKey() and null Keys

Since `HashMap` allows one `null` key, `containsKey()` can also check for it.

Example:

```java
fruitMap.put(null, 100);
```

Now:

```java
fruitMap.containsKey(null);
```

returns:

```text
true
```

This is valid for `HashMap`.

---

# 17. Why containsKey() is Useful with get()

Recall that:

```java
map.get(key);
```

returns `null` when there is no mapping for the requested key.

But `HashMap` also allows keys to be mapped to `null`.

Example:

```java
fruitMap.put("Mango", null);
```

Now:

```java
fruitMap.get("Mango");
```

returns:

```text
null
```

But:

```java
fruitMap.get("Papaya");
```

also returns:

```text
null
```

even if `"Papaya"` does not exist.

To distinguish the two situations, use:

```java
containsKey()
```

Example:

```java
if (fruitMap.containsKey("Mango")) {
    System.out.println("Mango key exists");
}
```

This is an important practical use of `containsKey()`.

---

# 18. Complete Example

```java
import java.util.HashMap;
import java.util.Map;

public class AccessHashMapExample {

    public static void main(String[] args) {

        Map<String, Integer> fruitMap = new HashMap<>();

        // Check before adding entries
        System.out.println(
                "Is the fruit map empty? " + fruitMap.isEmpty()
        );

        // Add key-value pairs
        fruitMap.put("Apple", 10);
        fruitMap.put("Banana", 20);
        fruitMap.put("Orange", 15);

        // Check after adding entries
        System.out.println(
                "Is the fruit map empty? " + fruitMap.isEmpty()
        );

        // Get total number of entries
        System.out.println(
                "Total fruits in inventory: " + fruitMap.size()
        );

        // Check whether a key exists
        if (fruitMap.containsKey("Banana")) {
            System.out.println("Key exists");
        } else {
            System.out.println("Key does not exist");
        }
    }
}
```

Possible output:

```text
Is the fruit map empty? true
Is the fruit map empty? false
Total fruits in inventory: 3
Key exists
```


```java
map.isEmpty();
```

```java
map.size();
```


```java
map.containsKey("Banana");
```

```text
true  -> Key exists
```

# Key Takeaway

The three important methods from this lecture are:

```java
isEmpty()
size()
containsKey()
```

Their jobs are simple:

```text
isEmpty()     -> Check whether the map is empty
size()        -> Count key-value pairs
containsKey() -> Check whether a specific key exists
```

The easiest way to remember them is:

> **`isEmpty()` checks emptiness, `size()` counts entries, and `containsKey()` searches for a key.**
