# Java HashMap – Removing Keys Using remove()

## 1. Objective

In this lecture, we will learn how to remove entries from a `HashMap`.

Java provides two commonly used overloaded `remove()` methods:

```java
remove(key)
remove(key, value)
```

We will understand:

* How to remove an entry using only the key
* What `remove(key)` returns
* What happens if the key does not exist
* How to remove an entry only when both key and value match
* What `remove(key, value)` returns
* The difference between the two overloaded methods

---

# 2. Create a Sample HashMap

First, create a `HashMap` containing some fruits and their quantities.

```java
import java.util.HashMap;
import java.util.Map;

public class RemoveKeysFromHashMapExample {

    public static void main(String[] args) {

        Map<String, Integer> fruitMap = new HashMap<>();

        fruitMap.put("Apple", 10);
        fruitMap.put("Banana", 20);
        fruitMap.put("Orange", 15);

        System.out.println(fruitMap);
    }
}
```

Conceptually:

```text
Apple   -> 10
Banana  -> 20
Orange  -> 15
```

---

# 3. remove(key)

The first overloaded `remove()` method removes an entry using its key.

Syntax:

```java
map.remove(key);
```

General method signature:

```java
V remove(Object key)
```

This method:

* Searches for the given key
* Removes the key and its associated value
* Returns the value that was removed
* Returns `null` if no mapping exists for the key

---

# 4. Removing an Entry Using a Key

Suppose the map contains:

```text
Apple   -> 10
Banana  -> 20
Orange  -> 15
```

To remove `"Apple"`:

```java
Integer removedValue = fruitMap.remove("Apple");
```

After this operation:

```text
Banana  -> 20
Orange  -> 15
```

The `"Apple"` entry has been removed completely.

---

# 5. Return Value of remove(key)

The `remove(key)` method returns the value that was associated with the removed key.

Example:

```java
Integer removedValue = fruitMap.remove("Apple");

System.out.println("Removed value: " + removedValue);
```

Since:

```text
Apple -> 10
```

the output is:

```text
Removed value: 10
```

Conceptually:

```text
fruitMap.remove("Apple")
        |
        v
Find Apple
        |
        v
Apple -> 10
        |
        +---- Remove entry
        |
        v
Return 10
```

---

# 6. Printing the Map After Removal

Example:

```java
System.out.println(
        "After removing Apple: " + fruitMap
);
```

Possible output:

```text
After removing Apple: {Orange=15, Banana=20}
```

Remember that `HashMap` does not guarantee insertion or iteration order, so the printed order may vary.

---

# 7. What Happens if the Key Does Not Exist?

Suppose `"Mango"` is not present.

```java
Integer removedValue = fruitMap.remove("Mango");
```

Since no mapping exists for `"Mango"`, the method returns:

```text
null
```

Example:

```java
System.out.println(fruitMap.remove("Mango"));
```

Output:

```text
null
```

Therefore:

```text
Existing key
    |
    v
remove(key)
    |
    v
Remove entry and return old value
```

But:

```text
Missing key
    |
    v
remove(key)
    |
    v
Return null
```

---

# 8. Important null Detail

Because `HashMap` allows `null` values, a returned `null` can sometimes be ambiguous.

For example:

```java
fruitMap.put("Mango", null);
```

Then:

```java
fruitMap.remove("Mango");
```

also returns:

```text
null
```

even though the `"Mango"` entry actually existed and was removed.

If you need to know whether the key existed before removal, you can check:

```java
fruitMap.containsKey("Mango");
```

before calling `remove()`.

---

# 9. remove(key, value)

The second overloaded method takes both a key and a value.

Syntax:

```java
map.remove(key, value);
```

General method signature:

```java
boolean remove(Object key, Object value)
```

This method removes the entry only when:

```text
Key matches
AND
Value matches
```

It returns:

```text
true  -> Entry was removed
false -> Entry was not removed
```

---

# 10. Removing When Key and Value Match

Suppose:

```text
Banana -> 20
```

Execute:

```java
boolean isRemoved = fruitMap.remove("Banana", 20);
```

Both the key and value match.

Therefore:

```text
Banana -> 20
```

is removed.

And:

```text
isRemoved = true
```

Example:

```java
boolean isRemoved = fruitMap.remove("Banana", 20);

System.out.println("Was Banana removed? " + isRemoved);
```

Output:

```text
Was Banana removed? true
```

---

# 11. Map After Successful remove(key, value)

Before:

```text
Banana -> 20
Orange -> 15
```

Execute:

```java
fruitMap.remove("Banana", 20);
```

After:

```text
Orange -> 15
```

Because both key and value matched.

---

# 12. When the Value Does Not Match

Suppose:

```text
Orange -> 15
```

But we execute:

```java
boolean result = fruitMap.remove("Orange", 20);
```

The key exists:

```text
Orange
```

But the value does not match:

```text
Actual value   = 15
Provided value = 20
```

Therefore the entry is **not removed**.

The method returns:

```text
false
```

Example:

```java
boolean result = fruitMap.remove("Orange", 20);

System.out.println(result);
```

Output:

```text
false
```

The map still contains:

```text
Orange -> 15
```

---

# 13. When the Key Does Not Exist

Suppose:

```java
boolean result = fruitMap.remove("Mango", 10);
```

If `"Mango"` does not exist, the method returns:

```text
false
```

because the requested key-value pair is not present.

---

# 14. How remove(key, value) Works

Conceptually:

```text
remove("Banana", 20)
        |
        v
Does Banana exist?
        |
       Yes
        |
        v
Is its value 20?
        |
       Yes
        |
        v
Remove Entry
        |
        v
Return true
```

But:

```text
remove("Orange", 20)
        |
        v
Does Orange exist?
        |
       Yes
        |
        v
Is its value 20?
        |
        No
        |
        v
Do NOT remove
        |
        v
Return false
```

---

# 15. Difference Between the Two remove() Methods

## remove(key)

```java
fruitMap.remove("Apple");
```

This method only checks the key.

If the key exists, the entire entry is removed.

Return value:

```text
The old value
```

or:

```text
null
```

if no mapping is found.

---

## remove(key, value)

```java
fruitMap.remove("Banana", 20);
```

This method checks both:

```text
Key
+
Value
```

The entry is removed only when both match.

Return value:

```text
true
```

or:

```text
false
```

---

# 16. Comparison Table

| Method               | Parameters    | Removal Condition        | Return Type    |
| -------------------- | ------------- | ------------------------ | -------------- |
| `remove(key)`        | Key           | Key exists               | Previous value |
| `remove(key, value)` | Key and value | Both key and value match | `boolean`      |

---

# 17. Example Comparison

Suppose:

```text
Apple  -> 10
Banana -> 20
```

### Using remove(key)

```java
Integer value = fruitMap.remove("Apple");
```

Result:

```text
Apple removed
value = 10
```

---

### Using remove(key, value)

```java
boolean result = fruitMap.remove("Banana", 20);
```

Result:

```text
Banana removed
result = true
```

---

### Wrong Value

```java
boolean result = fruitMap.remove("Banana", 50);
```

Result:

```text
Banana NOT removed
result = false
```

# 18. Complete Example

```java
import java.util.HashMap;
import java.util.Map;

public class RemoveKeysFromHashMapExample {

    public static void main(String[] args) {

        Map<String, Integer> fruitMap = new HashMap<>();

        fruitMap.put("Apple", 10);
        fruitMap.put("Banana", 20);
        fruitMap.put("Orange", 15);

        System.out.println("Original map: " + fruitMap);

        // Remove using key
        Integer removedValue = fruitMap.remove("Apple");

        System.out.println("Removed value: " + removedValue);
        System.out.println(
                "After removing Apple: " + fruitMap
        );

        // Trying to remove a key that doesn't exist
        System.out.println(
                "Removing Mango: " + fruitMap.remove("Mango")
        );

        // Remove using both key and value
        boolean isRemoved = fruitMap.remove("Banana", 20);

        System.out.println(
                "Was Banana removed? " + isRemoved
        );

        System.out.println(
                "After removing Banana: " + fruitMap
        );

        // Key exists, but value does not match
        boolean orangeRemoved = fruitMap.remove("Orange", 20);

        System.out.println(
                "Was Orange removed? " + orangeRemoved
        );

        System.out.println("Final map: " + fruitMap);
    }
}
```

Possible output:

```text
Original map: {Apple=10, Orange=15, Banana=20}

Removed value: 10

After removing Apple: {Orange=15, Banana=20}

Removing Mango: null

Was Banana removed? true

After removing Banana: {Orange=15}

Was Orange removed? false

Final map: {Orange=15}
```

The exact order of entries may differ because `HashMap` does not guarantee iteration order.

---

# 19. Practical Use Case for remove(key)

Use:

```java
remove(key)
```

when you only care about the key.

Example:

```java
userMap.remove("USER101");
```

This means:

```text
Remove USER101 regardless of its current value.
```

---

# 20. Practical Use Case for remove(key, value)

Use:

```java
remove(key, value)
```

when you want to remove an entry only if its current value is what you expect.

Example:

```java
statusMap.remove("ORDER101", "CANCELLED");
```

This means:

```text
Remove ORDER101
ONLY IF
its current value is CANCELLED.
```

This can be useful when you do not want to accidentally remove an entry whose value has changed.

---

```text
HashMap remove methods
        |
        +----------------------------+
        |                            |
        v                            v
remove(key)                 remove(key, value)
        |                            |
        v                            v
Find key                    Match key AND value
        |                            |
        v                            v
Remove entry                Remove only if both match
        |                            |
        v                            v
Return old value            Return true / false
```

# 22. Important Interview Questions

### How do you remove an entry from a HashMap using its key?

Use:

```java
map.remove(key);
```

---

### What does remove(key) return?

It returns the previous value associated with the removed key.

If there is no mapping for the key, it returns:

```text
null
```

---

### How do you remove an entry only when both key and value match?

Use:

```java
map.remove(key, value);
```

---

### What does remove(key, value) return?

```text
true  -> Entry was removed
false -> Entry was not removed
```

---

### What happens if the key exists but its value does not match?

Example:

```text
Orange -> 15
```

Calling:

```java
map.remove("Orange", 20);
```

returns:

```text
false
```

and the entry remains unchanged.

---

### Are the two remove() methods overloaded methods?

Yes.

They have the same method name:

```java
remove()
```

but different parameter lists:

```java
remove(Object key)

remove(Object key, Object value)
```

This is an example of **method overloading**.

---

# 23. Quick Memory Trick

Remember:

```text
remove(key)
    |
    +---- "Remove this KEY"


remove(key, value)
    |
    +---- "Remove this KEY only if
           it currently has this VALUE"
```

And their return values:

```text
remove(key)
    |
    +---- Returns old VALUE


remove(key, value)
    |
    +---- Returns BOOLEAN
```

---

# Key Takeaway

The two important overloaded methods are:

```java
map.remove(key);
map.remove(key, value);
```

Remember the difference:

> **`remove(key)` removes an entry based only on its key and returns the previous value.**

> **`remove(key, value)` removes the entry only when both the key and value match, and returns `true` or `false`.**

A simple memory shortcut:

```text
1 argument  -> remove by KEY
2 arguments -> remove by KEY + VALUE
```
