# Java `LinkedHashMap` --- Removing Entries

## Overview

This lesson explains how to remove entries from a Java `LinkedHashMap`.

You will learn how to:

-   Remove an entry using only its **key** with `remove(key)`.
-   Remove an entry only when both the **key and value match** using
    `remove(key, value)`.
-   Remove **all entries** using `clear()`.
-   Understand the return values of these removal methods.
-   Understand what happens to the remaining insertion order after
    entries are removed.

------------------------------------------------------------------------

## 1. Create a `LinkedHashMap`

Import the required classes:

``` java
import java.util.LinkedHashMap;
import java.util.Map;
```

Create the map and add some entries:

``` java
Map<String, Integer> wordNumberMapping =
        new LinkedHashMap<>();

wordNumberMapping.put("One", 1);
wordNumberMapping.put("Two", 2);
wordNumberMapping.put("Three", 3);
wordNumberMapping.put("Four", 4);
wordNumberMapping.put("Five", 5);
```

The map contains:

``` text
One   → 1
Two   → 2
Three → 3
Four  → 4
Five  → 5
```

Because this is a `LinkedHashMap`, normal iteration follows insertion
order.

------------------------------------------------------------------------

# 2. Methods Covered in This Lesson

There are three important removal operations:

``` java
remove(key)
remove(key, value)
clear()
```

Quick comparison:

  -----------------------------------------------------------------------
  Method                              Purpose
  ----------------------------------- -----------------------------------
  `remove(key)`                       Removes the mapping associated with
                                      a key

  `remove(key, value)`                Removes the mapping only if both
                                      key and value match

  `clear()`                           Removes every mapping from the map
  -----------------------------------------------------------------------

------------------------------------------------------------------------

# 3. Removing an Entry by Key --- `remove(key)`

The first form of `remove()` accepts a single argument:

``` java
map.remove(key);
```

It searches for the supplied key and removes its mapping.

Example:

``` java
wordNumberMapping.remove("Two");
```

Before:

``` text
One   → 1
Two   → 2
Three → 3
Four  → 4
Five  → 5
```

After:

``` text
One   → 1
Three → 3
Four  → 4
Five  → 5
```

The complete `"Two" → 2` mapping is removed.

------------------------------------------------------------------------

## 4. Printing the Map After Removal

``` java
wordNumberMapping.remove("Two");

System.out.println(
        "After removing key Two: " +
        wordNumberMapping
);
```

Output:

``` text
After removing key Two: {One=1, Three=3, Four=4, Five=5}
```

------------------------------------------------------------------------

# 5. Return Value of `remove(key)`

The single-argument `remove()` method returns the value that was
associated with the removed key.

Example:

``` java
Integer removedValue =
        wordNumberMapping.remove("Two");

System.out.println(removedValue);
```

If:

``` text
Two → 2
```

was present, the output is:

``` text
2
```

If there was no mapping for the requested key, the method normally
returns `null`.

Example:

``` java
Integer removedValue =
        wordNumberMapping.remove("Ten");
```

If `"Ten"` is absent:

``` text
removedValue = null
```

> Note: Because maps such as `LinkedHashMap` can themselves contain
> `null` values, a `null` return from `remove(key)` does not by itself
> always prove that the key was absent.

------------------------------------------------------------------------

# 6. Removing Using Both Key and Value

Java also provides:

``` java
remove(key, value)
```

This version removes an entry only when the supplied key is currently
associated with the supplied value.

Example:

``` java
wordNumberMapping.remove("Three", 3);
```

If the map contains:

``` text
Three → 3
```

then the entry is removed.

Before:

``` text
One   → 1
Three → 3
Four  → 4
Five  → 5
```

After:

``` text
One  → 1
Four → 4
Five → 5
```

------------------------------------------------------------------------

# 7. Why Use `remove(key, value)`?

Sometimes you do not want to remove an entry merely because the key
exists.

You want to remove it only when its current value is also what you
expect.

For example:

``` java
wordNumberMapping.remove("Three", 3);
```

means:

``` text
Remove "Three"
ONLY IF
"Three" currently maps to 3.
```

Decision flow:

``` text
remove("Three", 3)
         |
         v
Does "Three" exist and
currently map to 3?
         |
     +---+---+
     |       |
    YES      NO
     |       |
  Remove   Do nothing
```

------------------------------------------------------------------------

# 8. What Happens When the Value Is Wrong?

Suppose:

``` text
Three → 3
```

but you execute:

``` java
wordNumberMapping.remove("Three", 33);
```

The entry is **not removed**, because:

``` text
Expected by remove(): 33
Actual map value:       3

33 != 3
```

The map still contains:

``` text
Three → 3
```

This is an important difference between:

``` java
remove("Three");
```

and:

``` java
remove("Three", 33);
```

The first one only checks the key.

The second requires the key-value association to match.

------------------------------------------------------------------------

# 9. Return Value of `remove(key, value)`

The two-argument version returns a `boolean`.

Example:

``` java
boolean removed =
        wordNumberMapping.remove("Three", 3);
```

If the matching entry was removed:

``` text
removed = true
```

If the key/value combination did not match:

``` text
removed = false
```

This makes it easy to write:

``` java
if (wordNumberMapping.remove("Three", 3)) {

    System.out.println("Entry removed.");

} else {

    System.out.println("Entry was not removed.");
}
```

------------------------------------------------------------------------

# 10. `remove(key)` vs `remove(key, value)`

Suppose:

``` text
Three → 3
```

### Using only the key

``` java
wordNumberMapping.remove("Three");
```

Java asks:

``` text
Does key "Three" have a mapping?
        |
       YES
        |
      Remove
```

### Using key and value

``` java
wordNumberMapping.remove("Three", 3);
```

Java asks:

``` text
Does "Three" currently map to 3?
        |
       YES
        |
      Remove
```

Comparison:

  -----------------------------------------------------------------------
  Method                  Checks                  Result
  ----------------------- ----------------------- -----------------------
  `remove(key)`           Key                     Removes mapping for
                                                  that key

  `remove(key, value)`    Key + associated value  Removes only if both
                                                  match
  -----------------------------------------------------------------------

------------------------------------------------------------------------

# 11. Removing All Entries --- `clear()`

If you want to remove **every mapping** from a `LinkedHashMap`, use:

``` java
clear()
```

Example:

``` java
wordNumberMapping.clear();
```

Before:

``` text
One  → 1
Four → 4
Five → 5
```

After:

``` text
EMPTY MAP
```

Printing it:

``` java
System.out.println(wordNumberMapping);
```

Output:

``` text
{}
```

------------------------------------------------------------------------

# 12. Does `clear()` Delete the Map Object?

No.

This is an important beginner concept.

When you execute:

``` java
wordNumberMapping.clear();
```

the `LinkedHashMap` object still exists.

Its entries have simply been removed.

Conceptually:

``` text
Before clear():

wordNumberMapping
      |
      v
{One=1, Two=2, Three=3}


After clear():

wordNumberMapping
      |
      v
{}
```

You can add new entries afterward:

``` java
wordNumberMapping.clear();

wordNumberMapping.put("Six", 6);

System.out.println(wordNumberMapping);
```

Output:

``` text
{Six=6}
```

------------------------------------------------------------------------

# 13. Checking Whether the Map Is Empty

After using `clear()`, you can check:

``` java
wordNumberMapping.isEmpty();
```

Example:

``` java
wordNumberMapping.clear();

System.out.println(
        wordNumberMapping.isEmpty()
);
```

Output:

``` text
true
```

So:

``` text
clear()
   ↓
Remove all entries

isEmpty()
   ↓
Check whether there are zero entries
```

------------------------------------------------------------------------

# 14. What Happens to Insertion Order After Removal?

Suppose the map contains:

``` text
One   → 1
Two   → 2
Three → 3
Four  → 4
Five  → 5
```

Remove `"Two"`:

``` java
wordNumberMapping.remove("Two");
```

The remaining entries are:

``` text
One   → 1
Three → 3
Four  → 4
Five  → 5
```

The relative insertion order of the remaining entries is preserved.

This is another useful property of `LinkedHashMap`.

------------------------------------------------------------------------

# 15. Complete Runnable Example

``` java
import java.util.LinkedHashMap;
import java.util.Map;

public class RemoveFromLinkedHashMapExample {

    public static void main(String[] args) {

        // Create LinkedHashMap
        Map<String, Integer> wordNumberMapping =
                new LinkedHashMap<>();

        // Add entries
        wordNumberMapping.put("One", 1);
        wordNumberMapping.put("Two", 2);
        wordNumberMapping.put("Three", 3);
        wordNumberMapping.put("Four", 4);
        wordNumberMapping.put("Five", 5);

        System.out.println("Original Map:");
        System.out.println(wordNumberMapping);

        // --------------------------------
        // 1. Remove using key
        // --------------------------------

        wordNumberMapping.remove("Two");

        System.out.println(
                "After removing key Two:"
        );

        System.out.println(wordNumberMapping);

        // --------------------------------
        // 2. Remove using key and value
        // --------------------------------

        boolean removed =
                wordNumberMapping.remove("Three", 3);

        System.out.println(
                "Was Three=3 removed? " + removed
        );

        System.out.println(wordNumberMapping);

        // --------------------------------
        // 3. Try incorrect value
        // --------------------------------

        boolean removedWrongValue =
                wordNumberMapping.remove("Four", 44);

        System.out.println(
                "Was Four=44 removed? " +
                removedWrongValue
        );

        System.out.println(wordNumberMapping);

        // --------------------------------
        // 4. Remove all entries
        // --------------------------------

        wordNumberMapping.clear();

        System.out.println(
                "After clear():"
        );

        System.out.println(wordNumberMapping);

        System.out.println(
                "Is map empty? " +
                wordNumberMapping.isEmpty()
        );
    }
}
```

Typical output:

``` text
Original Map:
{One=1, Two=2, Three=3, Four=4, Five=5}

After removing key Two:
{One=1, Three=3, Four=4, Five=5}

Was Three=3 removed? true
{One=1, Four=4, Five=5}

Was Four=44 removed? false
{One=1, Four=4, Five=5}

After clear():
{}

Is map empty? true
```

# 19. Common Beginner Mistakes

### Mistake 1: Thinking `remove(key)` removes only the key

A map stores a mapping:

``` text
Key → Value
```

When you remove the key:

``` java
map.remove("Two");
```

the complete mapping is removed:

``` text
Two → 2
```

------------------------------------------------------------------------

### Mistake 2: Expecting `remove(key, wrongValue)` to remove the entry

Suppose:

``` text
Three → 3
```

This will **not** remove it:

``` java
map.remove("Three", 33);
```

because the value does not match.

------------------------------------------------------------------------

### Mistake 3: Thinking `clear()` destroys the map

This:

``` java
map.clear();
```

does not destroy the variable or map object.

It removes the mappings.

You can continue using the map afterward.

------------------------------------------------------------------------

# 20. Interview / Exam Points

1.  `remove(key)` removes the mapping associated with a key.
2.  `remove(key)` returns the previous value associated with that key.
3.  `remove(key, value)` removes an entry only when both key and value
    match.
4.  `remove(key, value)` returns a boolean.
5.  `true` means the matching entry was removed.
6.  `false` means the matching entry was not removed.
7.  `clear()` removes all mappings.
8.  After `clear()`, the map can still be reused.
9.  `isEmpty()` can check whether the map contains zero entries.
10. Removing entries from a `LinkedHashMap` preserves the relative order
    of the remaining entries.
