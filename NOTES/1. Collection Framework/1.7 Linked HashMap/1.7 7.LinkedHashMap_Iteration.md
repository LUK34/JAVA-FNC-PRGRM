# Java LinkedHashMap --- Different Ways to Iterate

## Overview

This lesson explains several ways to iterate through a Java
`LinkedHashMap`, all compatible with Java 8.

You will learn:

1.  `Map.forEach()` with a lambda expression.
2.  `entrySet().forEach()` with a lambda expression.
3.  `entrySet()` with an `Iterator`.
4.  `Iterator.forEachRemaining()` with a lambda expression.
5.  The enhanced `for` loop.

## 1. Create a LinkedHashMap

``` java
import java.util.Iterator;
import java.util.LinkedHashMap;
import java.util.Map;

Map<String, Integer> wordNumberMapping = new LinkedHashMap<>();

wordNumberMapping.put("One", 1);
wordNumberMapping.put("Two", 2);
wordNumberMapping.put("Three", 3);
wordNumberMapping.put("Four", 4);
wordNumberMapping.put("Five", 5);
```

Because this is a `LinkedHashMap`, its default iteration order follows
insertion order:

``` text
One → Two → Three → Four → Five
```

## 2. What Does Iteration Mean?

Iteration means visiting each entry one by one.

``` text
One → 1
   ↓
Two → 2
   ↓
Three → 3
```

During each iteration, your code can read or process the key and value.

## 3. Approach 1 --- Map.forEach() + Lambda

Java 8 provides `forEach()` directly on `Map`.

``` java
wordNumberMapping.forEach(
    (key, value) ->
        System.out.println(key + " -> " + value)
);
```

Output:

``` text
One -> 1
Two -> 2
Three -> 3
Four -> 4
Five -> 5
```

The lambda receives two parameters:

``` java
(key, value) -> ...
```

`Map.forEach()` uses a `BiConsumer`: one input is the key and the other
is the value.

If the lambda has only one statement, braces are optional.

``` java
wordNumberMapping.forEach((key, value) -> {
    System.out.println(key + " -> " + value);
});
```

can become:

``` java
wordNumberMapping.forEach(
    (key, value) -> System.out.println(key + " -> " + value)
);
```

## 4. Approach 2 --- entrySet().forEach() + Lambda

You can first retrieve the entry set and then iterate through it.

``` java
wordNumberMapping.entrySet().forEach(
    entry ->
        System.out.println(
            entry.getKey() + " -> " + entry.getValue()
        )
);
```

Each item is a `Map.Entry<String, Integer>`.

``` text
Map.Entry
├── getKey()
└── getValue()
```

The difference is:

``` text
map.forEach()
    → lambda receives KEY + VALUE

map.entrySet().forEach()
    → lambda receives one Map.Entry
```

## 5. Approach 3 --- Iterator + while Loop

Create an iterator from `entrySet()`:

``` java
Iterator<Map.Entry<String, Integer>> iterator =
    wordNumberMapping.entrySet().iterator();
```

Then use `hasNext()` and `next()`:

``` java
while (iterator.hasNext()) {

    Map.Entry<String, Integer> entry = iterator.next();

    System.out.println(
        entry.getKey() + " -> " + entry.getValue()
    );
}
```

`hasNext()` asks whether another element exists.

`next()` retrieves the next entry and advances the iterator.

``` text
Start
  ↓
hasNext()?
  ├── No → Stop
  └── Yes
        ↓
      next()
        ↓
   Process Entry
        ↓
   Repeat
```

## 6. Approach 4 --- Iterator.forEachRemaining()

Java 8 also provides `forEachRemaining()`.

``` java
Iterator<Map.Entry<String, Integer>> entryIterator =
    wordNumberMapping.entrySet().iterator();

entryIterator.forEachRemaining(
    entry ->
        System.out.println(
            entry.getKey() + " -> " + entry.getValue()
        )
);
```

It processes all entries remaining from the iterator's **current
position**.

For example:

``` text
Already consumed:
One, Two

Remaining:
Three, Four, Five
```

Calling `forEachRemaining()` at this point processes only:

``` text
Three
Four
Five
```

## 7. Approach 5 --- Enhanced for Loop

The enhanced `for` loop is another common and readable approach.

``` java
for (Map.Entry<String, Integer> entry :
        wordNumberMapping.entrySet()) {

    System.out.println(
        entry.getKey() + " -> " + entry.getValue()
    );
}
```

This means:

``` text
For each Map.Entry in entrySet()
        ↓
Get current entry
        ↓
getKey() / getValue()
        ↓
Process it
```

## 8. Complete Runnable Example

``` java
import java.util.Iterator;
import java.util.LinkedHashMap;
import java.util.Map;

public class IterateLinkedHashMapExample {

    public static void main(String[] args) {

        Map<String, Integer> wordNumberMapping =
                new LinkedHashMap<>();

        wordNumberMapping.put("One", 1);
        wordNumberMapping.put("Two", 2);
        wordNumberMapping.put("Three", 3);
        wordNumberMapping.put("Four", 4);
        wordNumberMapping.put("Five", 5);

        // 1. Map.forEach()
        System.out.println("1. Map.forEach()");

        wordNumberMapping.forEach(
            (key, value) ->
                System.out.println(key + " -> " + value)
        );

        // 2. entrySet().forEach()
        System.out.println("\n2. entrySet().forEach()");

        wordNumberMapping.entrySet().forEach(
            entry ->
                System.out.println(
                    entry.getKey() + " -> " + entry.getValue()
                )
        );

        // 3. Iterator + while
        System.out.println("\n3. Iterator + while");

        Iterator<Map.Entry<String, Integer>> iterator =
                wordNumberMapping.entrySet().iterator();

        while (iterator.hasNext()) {

            Map.Entry<String, Integer> entry =
                    iterator.next();

            System.out.println(
                entry.getKey() + " -> " + entry.getValue()
            );
        }

        // 4. Iterator.forEachRemaining()
        System.out.println("\n4. Iterator.forEachRemaining()");

        Iterator<Map.Entry<String, Integer>> entryIterator =
                wordNumberMapping.entrySet().iterator();

        entryIterator.forEachRemaining(
            entry ->
                System.out.println(
                    entry.getKey() + " -> " + entry.getValue()
                )
        );

        // 5. Enhanced for loop
        System.out.println("\n5. Enhanced for loop");

        for (Map.Entry<String, Integer> entry :
                wordNumberMapping.entrySet()) {

            System.out.println(
                entry.getKey() + " -> " + entry.getValue()
            );
        }
    }
}
```

## 10. BiConsumer vs Consumer

`Map.forEach()` receives two values:

``` java
(key, value) -> ...
```

This corresponds to a `BiConsumer`.

``` text
BiConsumer
├── Key
└── Value
```

`entrySet().forEach()` receives one `Map.Entry`:

``` java
entry -> ...
```

This corresponds to a `Consumer`.

``` text
Consumer
   ↓
Map.Entry
├── getKey()
└── getValue()
```

## 11. Which Approach Should You Use?

For simple key-value processing, this is concise:

``` java
map.forEach(
    (key, value) ->
        System.out.println(key + " -> " + value)
);
```

When working specifically with entries, the enhanced `for` loop is
clear:

``` java
for (Map.Entry<String, Integer> entry : map.entrySet()) {
    // process entry
}
```

Use an explicit `Iterator` when you need iterator-specific traversal
control. For example, an iterator can be useful when safely removing the
current entry during iteration using `iterator.remove()` where
supported.

## 12. Important LinkedHashMap Ordering

The approaches above follow the map's iteration order.

With the default insertion-order `LinkedHashMap`:

``` java
map.put("One", 1);
map.put("Two", 2);
map.put("Three", 3);
```

iteration follows:

``` text
One
Two
Three
```

This predictable ordering is an important feature of `LinkedHashMap`.

## 13. Common Beginner Mistakes

### `forEach()` vs enhanced `for`

These are different features.

Method call:

``` java
map.forEach((key, value) -> {
    // ...
});
```

Enhanced loop:

``` java
for (Map.Entry<String, Integer> entry : map.entrySet()) {
    // ...
}
```

### Forgetting hasNext()

The normal iterator pattern is:

``` java
while (iterator.hasNext()) {
    Map.Entry<String, Integer> entry = iterator.next();
}
```

### Assuming forEachRemaining() starts over

It does not. It processes elements from the iterator's current position.

### Using keySet() + get() when both parts are needed

This works:

``` java
for (String key : map.keySet()) {
    Integer value = map.get(key);
}
```

But when both key and value are naturally needed, `entrySet()` is
usually more direct:

``` java
for (Map.Entry<String, Integer> entry : map.entrySet()) {
    String key = entry.getKey();
    Integer value = entry.getValue();
}
```

## 14. Quick Cheat Sheet

``` java
// 1. Direct Map iteration
map.forEach(
    (key, value) ->
        System.out.println(key + " -> " + value)
);
```

``` java
// 2. Entry-set lambda
map.entrySet().forEach(
    entry ->
        System.out.println(
            entry.getKey() + " -> " + entry.getValue()
        )
);
```

``` java
// 3. Iterator
Iterator<Map.Entry<String, Integer>> iterator =
        map.entrySet().iterator();

while (iterator.hasNext()) {
    Map.Entry<String, Integer> entry = iterator.next();
}
```

``` java
// 4. forEachRemaining
iterator.forEachRemaining(
    entry ->
        System.out.println(
            entry.getKey() + " -> " + entry.getValue()
        )
);
```

``` java
// 5. Enhanced for
for (Map.Entry<String, Integer> entry : map.entrySet()) {
    System.out.println(
        entry.getKey() + " -> " + entry.getValue()
    );
}
```

## 15. Interview / Exam Points

1.  A `LinkedHashMap` can be iterated in several ways.
2.  `Map.forEach()` is available in Java 8.
3.  `Map.forEach()` works with a `BiConsumer`.
4.  Its lambda receives a key and a value.
5.  `entrySet()` provides `Map.Entry` objects.
6.  `Map.Entry.getKey()` retrieves the key.
7.  `Map.Entry.getValue()` retrieves the value.
8.  `Iterator.hasNext()` checks whether another element exists.
9.  `Iterator.next()` retrieves the next element.
10. `Iterator.forEachRemaining()` processes elements remaining from the
    iterator's current position.
11. The enhanced `for` loop is a readable way to iterate through
    `entrySet()`.
12. `LinkedHashMap` follows its defined ordering during iteration; by
    default this is insertion order.

## Final Summary

``` text
Map.forEach()
    → KEY + VALUE directly

entrySet().forEach()
    → ENTRY → getKey() + getValue()

Iterator
    → hasNext() + next()

forEachRemaining()
    → Process remaining iterator entries

Enhanced for
    → Simple iteration over entrySet()
```

For straightforward Java 8 key-value processing, `Map.forEach()` is
concise and expressive. The other approaches remain important because
each provides a different style or level of traversal control.
