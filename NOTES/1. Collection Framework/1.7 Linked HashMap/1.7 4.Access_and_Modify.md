# Java `LinkedHashMap` --- Accessing and Modifying Entries

## Overview

This lesson explains how to access and work with entries stored in a
Java `LinkedHashMap`.

You will learn how to:

-   Check whether a **key exists** using `containsKey()`.
-   Check whether a **value exists** using `containsValue()`.
-   Modify the value associated with an existing key using `put()`.
-   Understand the boolean results returned by `containsKey()` and
    `containsValue()`.

------------------------------------------------------------------------

## 1. Create a `LinkedHashMap`

First, import the required classes:

``` java
import java.util.LinkedHashMap;
import java.util.Map;
```

Then create a `LinkedHashMap`:

``` java
Map<String, Integer> wordNumberMapping =
        new LinkedHashMap<>();
```

Add some entries:

``` java
wordNumberMapping.put("One", 1);
wordNumberMapping.put("Two", 2);
wordNumberMapping.put("Three", 3);
wordNumberMapping.put("Four", 4);
wordNumberMapping.put("Five", 5);
```

The map contains:

``` text
One   → 1
Two   → 2
Three → 3
Four  → 4
Five  → 5
```

Because this is a `LinkedHashMap`, the entries normally iterate in
insertion order.

------------------------------------------------------------------------

# 2. Important Methods in This Lesson

The main methods are:

``` java
containsKey()
containsValue()
put()
```

Quick overview:

  Method                   Purpose
  ------------------------ -----------------------------------------------
  `containsKey(key)`       Checks whether a key exists
  `containsValue(value)`   Checks whether a value exists
  `put(key, value)`        Adds a new mapping or updates an existing key

------------------------------------------------------------------------

# 3. Checking Whether a Key Exists --- `containsKey()`

Use:

``` java
containsKey()
```

when you want to determine whether a particular key exists in the map.

Syntax:

``` java
map.containsKey(key);
```

It returns a `boolean`:

``` text
true  → key exists
false → key does not exist
```

------------------------------------------------------------------------

## Example

``` java
String key = "Two";

boolean exists = wordNumberMapping.containsKey(key);

System.out.println(exists);
```

Output:

``` text
true
```

Why?

Because the map contains:

``` text
Two → 2
```

------------------------------------------------------------------------

# 4. Using `containsKey()` with an `if` Statement

Because `containsKey()` returns a boolean, it can be used directly
inside an `if` condition.

``` java
String key = "Two";

if (wordNumberMapping.containsKey(key)) {

    System.out.println(
        "Key " + key + " exists in the LinkedHashMap."
    );

} else {

    System.out.println(
        "Key " + key + " does not exist in the LinkedHashMap."
    );
}
```

Output:

``` text
Key Two exists in the LinkedHashMap.
```

The flow is:

``` text
containsKey("Two")
        |
        v
Does "Two" exist?
        |
    +---+---+
    |       |
   YES      NO
    |       |
  true     false
```

------------------------------------------------------------------------

# 5. What Happens for a Missing Key?

Suppose:

``` java
String key = "Ten";
```

Then:

``` java
wordNumberMapping.containsKey("Ten");
```

returns:

``` text
false
```

because `"Ten"` is not one of the stored keys.

Example:

``` java
if (wordNumberMapping.containsKey("Ten")) {

    System.out.println("Key exists.");

} else {

    System.out.println("Key does not exist.");
}
```

Output:

``` text
Key does not exist.
```

------------------------------------------------------------------------

# 6. Checking Whether a Value Exists --- `containsValue()`

Use:

``` java
containsValue()
```

to determine whether a particular **value** exists somewhere in the map.

Syntax:

``` java
map.containsValue(value);
```

It also returns a boolean:

``` text
true  → value exists
false → value does not exist
```

------------------------------------------------------------------------

## Example

Suppose the map contains:

``` text
One   → 1
Two   → 2
Three → 3
Four  → 4
Five  → 5
```

Check for the value `3`:

``` java
Integer value = 3;

boolean exists =
        wordNumberMapping.containsValue(value);

System.out.println(exists);
```

Output:

``` text
true
```

because:

``` text
Three → 3
        ↑
      found
```

------------------------------------------------------------------------

# 7. Using `containsValue()` with an `if` Statement

``` java
Integer value = 3;

if (wordNumberMapping.containsValue(value)) {

    System.out.println(
        "Value " + value + " exists in the LinkedHashMap."
    );

} else {

    System.out.println(
        "Value " + value + " does not exist in the LinkedHashMap."
    );
}
```

Output:

``` text
Value 3 exists in the LinkedHashMap.
```

The decision flow is:

``` text
containsValue(3)
       |
       v
Does value 3 exist?
       |
   +---+---+
   |       |
  YES      NO
   |       |
 true     false
```

------------------------------------------------------------------------

# 8. `containsKey()` vs `containsValue()`

These methods sound similar but check different parts of the map.

Suppose:

``` text
Three → 3
```

Then:

``` java
wordNumberMapping.containsKey("Three");
```

checks:

``` text
"Three"
   ↑
  KEY
```

Whereas:

``` java
wordNumberMapping.containsValue(3);
```

checks:

``` text
3
↑
VALUE
```

Comparison:

  Method                   Searches For   Returns
  ------------------------ -------------- -----------
  `containsKey(key)`       Key            `boolean`
  `containsValue(value)`   Value          `boolean`

------------------------------------------------------------------------

# 9. Modifying an Existing Value with `put()`

The `put()` method is not only used to add new entries.

It can also update the value associated with an existing key.

Suppose the map contains:

``` text
Three → 3
```

Now execute:

``` java
wordNumberMapping.put("Three", 33);
```

The result becomes:

``` text
Three → 33
```

The old value `3` is replaced with `33`.

------------------------------------------------------------------------

# 10. Why Does `put()` Update the Value?

Keys in a `Map` must be unique.

Therefore:

``` java
wordNumberMapping.put("Three", 3);
wordNumberMapping.put("Three", 33);
```

does **not** create:

``` text
Three → 3
Three → 33
```

Instead:

``` text
Initial:

Three → 3

        ↓

put("Three", 33)

        ↓

Updated:

Three → 33
```

So remember:

``` text
put(newKey, value)
        ↓
Add new entry


put(existingKey, newValue)
        ↓
Update existing value
```

------------------------------------------------------------------------

# 11. Does Updating Change the Insertion Position?

In a normal insertion-order `LinkedHashMap`, updating the value of an
existing key does not normally move that entry to the end.

Example:

``` java
Map<String, Integer> map = new LinkedHashMap<>();

map.put("One", 1);
map.put("Two", 2);
map.put("Three", 3);

map.put("Two", 22);

System.out.println(map);
```

Output:

``` text
{One=1, Two=22, Three=3}
```

The order remains:

``` text
One
Two
Three
```

Only the value associated with `"Two"` changed.

------------------------------------------------------------------------

# 12. Complete Example

``` java
import java.util.LinkedHashMap;
import java.util.Map;

public class AccessLinkedHashMapExample {

    public static void main(String[] args) {

        // Create LinkedHashMap
        Map<String, Integer> wordNumberMapping =
                new LinkedHashMap<>();

        // Add entries
        wordNumberMapping.put("One", 1);
        wordNumberMapping.put("Two", 2);
        wordNumberMapping.put("Three", 3);
        wordNumberMapping.put("Four", 4);
        wordNumberMapping.put("Five", 5);

        System.out.println("Original Map:");
        System.out.println(wordNumberMapping);

        // --------------------------------
        // Check whether a key exists
        // --------------------------------

        String key = "Two";

        if (wordNumberMapping.containsKey(key)) {

            System.out.println(
                "Key " + key +
                " exists in the LinkedHashMap."
            );

        } else {

            System.out.println(
                "Key " + key +
                " does not exist in the LinkedHashMap."
            );
        }

        // --------------------------------
        // Check whether a value exists
        // --------------------------------

        Integer value = 3;

        if (wordNumberMapping.containsValue(value)) {

            System.out.println(
                "Value " + value +
                " exists in the LinkedHashMap."
            );

        } else {

            System.out.println(
                "Value " + value +
                " does not exist in the LinkedHashMap."
            );
        }

        // --------------------------------
        // Modify an existing value
        // --------------------------------

        wordNumberMapping.put("Three", 33);

        System.out.println("Updated Map:");
        System.out.println(wordNumberMapping);
    }
}
```

Typical output:

``` text
Original Map:
{One=1, Two=2, Three=3, Four=4, Five=5}

Key Two exists in the LinkedHashMap.

Value 3 exists in the LinkedHashMap.

Updated Map:
{One=1, Two=2, Three=33, Four=4, Five=5}
```

# 13. Accessing the Value of a Key

Although the lecture focuses on `containsKey()`, `containsValue()`, and
`put()`, remember that `get()` is the normal method used when you
actually want to retrieve the value associated with a key.

Example:

``` java
Integer number =
        wordNumberMapping.get("Three");

System.out.println(number);
```

If the map contains:

``` text
Three → 33
```

the output is:

``` text
33
```

So:

``` text
containsKey()
    → Does this key exist?

get()
    → Give me the value for this key.
```

------------------------------------------------------------------------

# 14. Common Beginner Mistake

Do not confuse:

``` java
containsKey("Three")
```

with:

``` java
containsValue(3)
```

Given:

``` text
Three → 3
```

think of it like:

``` text
+---------+-------+
| KEY     | VALUE |
+---------+-------+
| One     | 1     |
| Two     | 2     |
| Three   | 3     |
+---------+-------+
     ↑        ↑
     |        |
containsKey  containsValue
```

# 16. Method Cheat Sheet

``` java
// Does key exist?
map.containsKey("Two");

// Does value exist?
map.containsValue(3);

// Retrieve value
map.get("Three");

// Add new entry
map.put("Six", 6);

// Update existing entry
map.put("Three", 33);
```

------------------------------------------------------------------------

# 17. Interview / Exam Points

1.  `containsKey()` checks whether a particular key exists.
2.  `containsKey()` returns `true` or `false`.
3.  `containsValue()` checks whether a particular value exists.
4.  `containsValue()` also returns `true` or `false`.
5.  `put()` can add a new key-value pair.
6.  `put()` can also update the value of an existing key.
7.  Map keys must be unique.
8.  Updating an existing key does not create a duplicate key.
9.  `get()` retrieves the value associated with a key.
10. `LinkedHashMap` maintains predictable insertion-order iteration by
    default.
