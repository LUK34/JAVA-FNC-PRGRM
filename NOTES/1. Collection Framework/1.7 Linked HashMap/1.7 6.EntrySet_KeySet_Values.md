# Java `LinkedHashMap` --- `entrySet()`, `keySet()`, and `values()`

## Overview

This lesson explains three very important methods used to retrieve data
from a Java `LinkedHashMap`:

-   `entrySet()` --- retrieve **key-value pairs**
-   `keySet()` --- retrieve **keys**
-   `values()` --- retrieve **values**

These methods are especially useful when you need to iterate through the
contents of a map.

------------------------------------------------------------------------

# 1. Create a `LinkedHashMap`

Import the required classes:

``` java
import java.util.Collection;
import java.util.LinkedHashMap;
import java.util.Map;
import java.util.Set;
```

Create the map:

``` java
Map<String, Integer> wordNumberMapping =
        new LinkedHashMap<>();
```

Add some entries:

``` java
wordNumberMapping.put("One", 1);
wordNumberMapping.put("Two", 2);
wordNumberMapping.put("Three", 3);
wordNumberMapping.put("Four", 4);
wordNumberMapping.put("Five", 5);
```

The map contains:

``` text
One   → 1
Two   → 2
Three → 3
Four  → 4
Five  → 5
```

Print the map:

``` java
System.out.println(wordNumberMapping);
```

Output:

``` text
{One=1, Two=2, Three=3, Four=4, Five=5}
```

Because this is a `LinkedHashMap`, the normal iteration order follows
insertion order.

------------------------------------------------------------------------

# 2. Three Ways to View Map Data

Think of a map as a table:

``` text
+---------+-------+
| KEY     | VALUE |
+---------+-------+
| One     | 1     |
| Two     | 2     |
| Three   | 3     |
| Four    | 4     |
| Five    | 5     |
+---------+-------+
```

Java gives us three useful views:

``` text
entrySet()
    ↓
KEY + VALUE


keySet()
    ↓
KEY only


values()
    ↓
VALUE only
```

------------------------------------------------------------------------

# 3. `entrySet()` --- Retrieve Key-Value Pairs

Use:

``` java
entrySet()
```

when you need both the **key and value**.

Syntax:

``` java
map.entrySet();
```

For our map:

``` java
Set<Map.Entry<String, Integer>> entries =
        wordNumberMapping.entrySet();
```

Why this type?

``` text
Set
 |
 └── Map.Entry<String, Integer>
              |         |
              |         └── Value type
              |
              └── Key type
```

Each `Map.Entry` represents one key-value mapping.

For example:

``` text
One=1
```

represents:

``` text
Key   = "One"
Value = 1
```

------------------------------------------------------------------------

# 4. Printing the Entry Set

``` java
Set<Map.Entry<String, Integer>> entries =
        wordNumberMapping.entrySet();

System.out.println("Entries: " + entries);
```

Output:

``` text
Entries: [One=1, Two=2, Three=3, Four=4, Five=5]
```

------------------------------------------------------------------------

# 5. Iterating Through `entrySet()`

One of the most common ways to iterate through a map is:

``` java
for (Map.Entry<String, Integer> entry :
        wordNumberMapping.entrySet()) {

    System.out.println(
            entry.getKey() + " -> " +
            entry.getValue()
    );
}
```

Output:

``` text
One -> 1
Two -> 2
Three -> 3
Four -> 4
Five -> 5
```

Inside the loop:

``` java
entry.getKey()
```

retrieves the key.

And:

``` java
entry.getValue()
```

retrieves the value.

------------------------------------------------------------------------

# 6. When Should You Use `entrySet()`?

Use `entrySet()` when you need:

``` text
Key AND Value
```

For example:

``` java
for (Map.Entry<String, Integer> entry :
        wordNumberMapping.entrySet()) {

    String key = entry.getKey();
    Integer value = entry.getValue();

    System.out.println(
            "Key: " + key +
            ", Value: " + value
    );
}
```

This is generally preferable to iterating over keys and repeatedly
calling `get()` when both pieces of information are required.

------------------------------------------------------------------------

# 7. `keySet()` --- Retrieve All Keys

Use:

``` java
keySet()
```

when you only need the keys.

Syntax:

``` java
map.keySet();
```

Example:

``` java
Set<String> keys =
        wordNumberMapping.keySet();
```

The return type is:

``` text
Set<String>
```

because the map's keys are `String` values.

------------------------------------------------------------------------

# 8. Printing the Keys

``` java
Set<String> keys =
        wordNumberMapping.keySet();

System.out.println("Keys: " + keys);
```

Output:

``` text
Keys: [One, Two, Three, Four, Five]
```

------------------------------------------------------------------------

# 9. Why Does `keySet()` Return a `Set`?

Map keys must be unique.

For example, a map cannot contain:

``` text
One → 1
One → 100
```

as two separate entries.

The second mapping would replace the value associated with the existing
key.

Since keys are unique, `keySet()` naturally returns a:

``` java
Set<K>
```

In our example:

``` java
Set<String>
```

------------------------------------------------------------------------

# 10. Iterating Through Keys

``` java
for (String key : wordNumberMapping.keySet()) {

    System.out.println(key);
}
```

Output:

``` text
One
Two
Three
Four
Five
```

If you need the value as well, you could call:

``` java
wordNumberMapping.get(key);
```

Example:

``` java
for (String key : wordNumberMapping.keySet()) {

    Integer value =
            wordNumberMapping.get(key);

    System.out.println(
            key + " -> " + value
    );
}
```

However, when you need **both key and value**, `entrySet()` is usually
the more direct approach.

------------------------------------------------------------------------

# 11. `values()` --- Retrieve All Values

Use:

``` java
values()
```

when you only need the values stored in the map.

Syntax:

``` java
map.values();
```

Example:

``` java
Collection<Integer> values =
        wordNumberMapping.values();
```

Notice that the return type is:

``` text
Collection<Integer>
```

and not:

``` text
Set<Integer>
```

This distinction is important.

------------------------------------------------------------------------

# 12. Why Does `values()` Return a `Collection`?

Map keys must be unique, but map **values do not have to be unique**.

For example:

``` java
Map<String, Integer> scores =
        new LinkedHashMap<>();

scores.put("John", 100);
scores.put("Sarah", 100);
scores.put("David", 90);
```

The values are:

``` text
100
100
90
```

Duplicate values are allowed.

Therefore:

``` java
values()
```

returns:

``` java
Collection<V>
```

rather than a `Set<V>`.

------------------------------------------------------------------------

# 13. Printing the Values

``` java
Collection<Integer> values =
        wordNumberMapping.values();

System.out.println("Values: " + values);
```

Output:

``` text
Values: [1, 2, 3, 4, 5]
```

------------------------------------------------------------------------

# 14. Iterating Through Values

``` java
for (Integer value :
        wordNumberMapping.values()) {

    System.out.println(value);
}
```

Output:

``` text
1
2
3
4
5
```

Use this approach when you do not need the corresponding keys.

------------------------------------------------------------------------

This is worth remembering for exams and interviews.

``` java

```

returns:

``` java

```

------------------------------------------------------------------------

``` java

```

returns:

``` java

```

------------------------------------------------------------------------

For:

# 18. Complete Runnable Example

``` java
import java.util.Collection;
import java.util.LinkedHashMap;
import java.util.Map;
import java.util.Set;

public class EntrySetKeysValuesLinkedHashMapExample {

    public static void main(String[] args) {

        // Create LinkedHashMap
        Map<String, Integer> wordNumberMapping =
                new LinkedHashMap<>();

        // Add entries
        wordNumberMapping.put("One", 1);
        wordNumberMapping.put("Two", 2);
        wordNumberMapping.put("Three", 3);
        wordNumberMapping.put("Four", 4);
        wordNumberMapping.put("Five", 5);

        // Print complete map
        System.out.println(
                "Map: " + wordNumberMapping
        );

        // --------------------------------
        // 1. Get all entries
        // --------------------------------

        Set<Map.Entry<String, Integer>> entries =
                wordNumberMapping.entrySet();

        System.out.println(
                "Entries: " + entries
        );

        // --------------------------------
        // 2. Get all keys
        // --------------------------------

        Set<String> keys =
                wordNumberMapping.keySet();

        System.out.println(
                "Keys: " + keys
        );

        // --------------------------------
        // 3. Get all values
        // --------------------------------

        Collection<Integer> values =
                wordNumberMapping.values();

        System.out.println(
                "Values: " + values
        );
    }
}
```

Typical output:

``` text
Map: {One=1, Two=2, Three=3, Four=4, Five=5}

Entries: [One=1, Two=2, Three=3, Four=4, Five=5]

Keys: [One, Two, Three, Four, Five]

Values: [1, 2, 3, 4, 5]
```

# 19. Complete Iteration Example

``` java
import java.util.LinkedHashMap;
import java.util.Map;

public class LinkedHashMapIterationExample {

    public static void main(String[] args) {

        Map<String, Integer> map =
                new LinkedHashMap<>();

        map.put("One", 1);
        map.put("Two", 2);
        map.put("Three", 3);

        // -------------------------------
        // Iterate through entries
        // -------------------------------

        System.out.println("Entries:");

        for (Map.Entry<String, Integer> entry :
                map.entrySet()) {

            System.out.println(
                    entry.getKey() +
                    " -> " +
                    entry.getValue()
            );
        }

        // -------------------------------
        // Iterate through keys
        // -------------------------------

        System.out.println("Keys:");

        for (String key : map.keySet()) {

            System.out.println(key);
        }

        // -------------------------------
        // Iterate through values
        // -------------------------------

        System.out.println("Values:");

        for (Integer value : map.values()) {

            System.out.println(value);
        }
    }
}
```

# 20. Choosing the Correct Method

Ask yourself:

``` text
What information do I need?
          |
   +------+------+
   |             |
Key + Value     Only one part
   |             |
entrySet()    +--+--+
              |     |
             Key   Value
              |     |
          keySet() values()
```

So:

``` text
Need both key and value?
        → entrySet()

Need only keys?
        → keySet()

Need only values?
        → values()
```

------------------------------------------------------------------------

# 21. Important `LinkedHashMap` Ordering Behavior

Because the map in these examples is a `LinkedHashMap`, the views
produced by:

``` java
entrySet()
keySet()
values()
```

iterate according to the map's ordering.

For the default insertion-order mode:

``` java
map.put("One", 1);
map.put("Two", 2);
map.put("Three", 3);
```

you can expect iteration to follow:

``` text
One
Two
Three
```

This predictable ordering is one of the main differences between
`LinkedHashMap` and ordinary `HashMap`.

------------------------------------------------------------------------

# 22. Important Advanced Note: These Are Views

`entrySet()`, `keySet()`, and `values()` return **views backed by the
map** rather than completely independent copies.

For example:

``` java
Set<String> keys =
        wordNumberMapping.keySet();

wordNumberMapping.remove("Two");

System.out.println(keys);
```

The `"Two"` key will no longer appear in the `keys` view because it
reflects the map.

This is useful to know as you progress beyond the beginner level.

------------------------------------------------------------------------

# 23. Common Beginner Mistakes

## Mistake 1: Using `keySet()` when both key and value are needed

You can write:

``` java
for (String key : map.keySet()) {

    Integer value = map.get(key);
}
```

But when you naturally need both pieces, this is clearer:

``` java
for (Map.Entry<String, Integer> entry :
        map.entrySet()) {

    String key = entry.getKey();
    Integer value = entry.getValue();
}
```

------------------------------------------------------------------------

## Mistake 2: Assuming `values()` returns a `Set`

This is incorrect:

``` java
Set<Integer> values = map.values();
```

The correct type is:

``` java
Collection<Integer> values =
        map.values();
```

Why?

Because duplicate values are allowed.

------------------------------------------------------------------------

## Mistake 3: Confusing keys and values

Given:

``` text
Three → 3
```

remember:

``` text
"Three"
    ↓
   KEY


3
↓
VALUE
```

