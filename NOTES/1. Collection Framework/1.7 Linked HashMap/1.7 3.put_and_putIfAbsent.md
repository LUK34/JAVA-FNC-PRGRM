# Java `LinkedHashMap` --- Creating a Map and Adding Key-Value Pairs

## Overview

This lesson explains how to:

-   Create a `LinkedHashMap`.
-   Add key-value pairs using `put()`.
-   Add a value conditionally using `putIfAbsent()`.
-   Understand the difference between `put()` and `putIfAbsent()`.
-   Print a `LinkedHashMap`.
-   Understand what happens when a duplicate key is used.

------------------------------------------------------------------------

## 1. Import the Required Classes

`LinkedHashMap` and `Map` are part of the `java.util` package.

``` java
import java.util.LinkedHashMap;
import java.util.Map;
```

------------------------------------------------------------------------

## 2. Creating a `LinkedHashMap`

A `LinkedHashMap` stores data as:

``` text
Key → Value
```

For example, suppose we want to store a word and its corresponding
number:

``` text
"One"   → 1
"Two"   → 2
"Three" → 3
```

We can create the map as follows:

``` java
Map<String, Integer> wordNumberMapping =
        new LinkedHashMap<>();
```

Here:

``` text
Map<String, Integer>
    │        │
    │        └── Value type = Integer
    │
    └── Key type = String
```

`wordNumberMapping` is the reference variable.

The actual object created is:

``` java
new LinkedHashMap<>()
```

------------------------------------------------------------------------

## 3. Why Use `Map` as the Reference Type?

You could write:

``` java
LinkedHashMap<String, Integer> wordNumberMapping =
        new LinkedHashMap<>();
```

This is valid.

However, it is common to program to the `Map` interface:

``` java
Map<String, Integer> wordNumberMapping =
        new LinkedHashMap<>();
```

The simplified relationship is:

``` text
Map
 ↑
HashMap
 ↑
LinkedHashMap
```

Using the interface as the variable type makes the code less dependent
on one particular map implementation when only `Map` operations are
required.

------------------------------------------------------------------------

# 4. Adding Entries with `put()`

The `put()` method adds a key-value mapping.

Syntax:

``` java
map.put(key, value);
```

Example:

``` java
wordNumberMapping.put("One", 1);
wordNumberMapping.put("Two", 2);
wordNumberMapping.put("Three", 3);
wordNumberMapping.put("Four", 4);
wordNumberMapping.put("Five", 5);
```

The map now contains:

``` text
One   → 1
Two   → 2
Three → 3
Four  → 4
Five  → 5
```

Because this is a `LinkedHashMap`, normal iteration follows insertion
order.

------------------------------------------------------------------------

# 5. What Happens If `put()` Uses an Existing Key?

Map keys must be unique.

Suppose the map already contains:

``` java
wordNumberMapping.put("Five", 5);
```

and later we execute:

``` java
wordNumberMapping.put("Five", 10);
```

Java does **not** create another `"Five"` key.

Instead, the existing value is replaced:

``` text
Before:

Five → 5

put("Five", 10)

After:

Five → 10
```

So:

> `put()` adds a new mapping when the key is new, but replaces the
> existing value when the key is already present.

------------------------------------------------------------------------

# 6. Return Value of `put()`

`put()` also returns the previous value associated with the key.

Example:

``` java
Integer oldValue = wordNumberMapping.put("Five", 10);
```

If `"Five"` previously mapped to `5`:

``` text
oldValue = 5
```

If the key had no previous mapping, the method normally returns:

``` text
null
```

This can be useful when you need to know whether a previous value was
replaced.

------------------------------------------------------------------------

# 7. Adding Entries with `putIfAbsent()`

`putIfAbsent()` is useful when you only want to establish a value when
the key does not currently have a non-null value.

Syntax:

``` java
map.putIfAbsent(key, value);
```

Example:

``` java
wordNumberMapping.putIfAbsent("Six", 6);
```

If `"Six"` is not currently present, the mapping is added:

``` text
Six → 6
```

------------------------------------------------------------------------

# 8. What If the Key Already Exists?

Suppose:

``` java
wordNumberMapping.putIfAbsent("Six", 6);
```

The map contains:

``` text
Six → 6
```

Now execute:

``` java
wordNumberMapping.putIfAbsent("Six", 10);
```

Because `"Six"` already maps to a non-null value, `putIfAbsent()` leaves
it unchanged.

Result:

``` text
Six → 6
```

It does **not** become:

``` text
Six → 10
```

------------------------------------------------------------------------

# 9. `put()` vs `putIfAbsent()`

This is the key concept from the lesson.

### `put()`

``` java
map.put(key, value);
```

If the key does not exist:

``` text
New mapping is added
```

If the key already exists:

``` text
Existing value is replaced
```

### `putIfAbsent()`

``` java
map.putIfAbsent(key, value);
```

If the key is absent:

``` text
New mapping is added
```

If the key already maps to a non-null value:

``` text
Existing value is preserved
```

If the key is mapped to `null`, `putIfAbsent()` can associate the
supplied non-null value with that key.

------------------------------------------------------------------------

## 10. Comparison Table

  -----------------------------------------------------------------------
  Situation               `put()`                 `putIfAbsent()`
  ----------------------- ----------------------- -----------------------
  Key does not exist      Adds mapping            Adds mapping

  Key exists with a       Replaces value          Keeps existing value
  non-null value                                  

  Key is mapped to `null` Stores new value        Stores supplied value

  Useful when             You want to add/update  You want to avoid
                                                  replacing an existing
                                                  non-null value
  -----------------------------------------------------------------------

# 11. Visual Example

Start with:

``` text
Five → 5
Six  → 6
```

Execute:

``` java
wordNumberMapping.put("Five", 10);
```

Result:

``` text
Five → 10
Six  → 6
```

Now execute:

``` java
wordNumberMapping.putIfAbsent("Six", 10);
```

Result remains:

``` text
Five → 10
Six  → 6
```

Why?

``` text
put("Five", 10)
       ↓
Five already exists
       ↓
Replace 5 with 10


putIfAbsent("Six", 10)
       ↓
Six already has value 6
       ↓
Do not replace it
```

# 12. Complete Example

``` java
import java.util.LinkedHashMap;
import java.util.Map;

public class CreateLinkedHashMapExample {

    public static void main(String[] args) {

        // Create LinkedHashMap
        Map<String, Integer> wordNumberMapping =
                new LinkedHashMap<>();

        // Add key-value pairs using put()
        wordNumberMapping.put("One", 1);
        wordNumberMapping.put("Two", 2);
        wordNumberMapping.put("Three", 3);
        wordNumberMapping.put("Four", 4);
        wordNumberMapping.put("Five", 5);

        System.out.println("Initial Map:");
        System.out.println(wordNumberMapping);

        // Add a new mapping using putIfAbsent()
        wordNumberMapping.putIfAbsent("Six", 6);

        System.out.println("After putIfAbsent(\"Six\", 6):");
        System.out.println(wordNumberMapping);

        // Existing key: value will NOT be replaced
        wordNumberMapping.putIfAbsent("Six", 10);

        System.out.println("After putIfAbsent(\"Six\", 10):");
        System.out.println(wordNumberMapping);

        // Existing key: put() WILL replace its value
        wordNumberMapping.put("Five", 10);

        System.out.println("After put(\"Five\", 10):");
        System.out.println(wordNumberMapping);
    }
}
```

Typical final output:

``` text
{One=1, Two=2, Three=3, Four=4, Five=10, Six=6}
```

# 13. Printing a `LinkedHashMap`

The simplest way to print the complete map is:

``` java
System.out.println(wordNumberMapping);
```

Example:

``` text
{One=1, Two=2, Three=3, Four=4, Five=5, Six=6}
```

The general display format is:

``` text
{key=value, key=value, key=value}
```

# 14. Important Note About `null`

The lecture mentions an important detail about `putIfAbsent()`.

Consider:

``` java
Map<String, Integer> map = new LinkedHashMap<>();

map.put("Seven", null);
```

The key exists, but its value is `null`.

Now:

``` java
map.putIfAbsent("Seven", 7);
```

The result becomes:

``` text
Seven → 7
```

So a useful beginner rule is:

> `putIfAbsent()` assigns the supplied value when the key has no current
> non-null value.

------------------------------------------------------------------------

# 15. Common Beginner Mistake

Do not think that:

``` java
map.put("Five", 5);
map.put("Five", 10);
```

creates:

``` text
Five → 5
Five → 10
```

That is impossible because map keys must be unique.

The actual result is:

``` text
Five → 10
```

The second `put()` updates the value associated with the existing key.

# 17. `put()` Decision Flow

``` text
put(key, value)
      |
      v
Does key already exist?
      |
  +---+---+
  |       |
 NO      YES
  |       |
 Add    Replace
 entry   value
```

# 18. `putIfAbsent()` Decision Flow

For the common non-null case:

``` text
putIfAbsent(key, value)
          |
          v
Does key already have
a non-null value?
          |
      +---+---+
      |       |
     NO      YES
      |       |
   Store     Keep
   value    existing
             value
```

# 19. Interview / Exam Points

1.  `LinkedHashMap` is available in `java.util`.
2.  `LinkedHashMap` extends `HashMap`.
3.  It can be referenced using the `Map` interface.
4.  `put()` is used to add or replace mappings.
5.  Keys in a map must be unique.
6.  `put()` replaces the value associated with an existing key.
7.  `putIfAbsent()` does not replace an existing non-null mapping.
8.  `putIfAbsent()` can assign a value when the key is absent or
    currently mapped to `null`.
9.  `LinkedHashMap` maintains predictable insertion-order iteration by
    default.
10. `System.out.println(map)` can be used to quickly inspect the map's
    contents.
